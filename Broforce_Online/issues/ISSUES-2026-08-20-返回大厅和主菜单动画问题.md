# 2026-08-20 在线大厅返回主菜单问题记录

## 问题范围

本记录整理 Workshop 三方地图线上会话中，按 `Esc` 返回在线房间大厅，以及从在线房间大厅返回主菜单时发现的导航和界面时序问题。

本次涉及两个连续流程：

```text
地图内 Esc
  -> 跳过通关时间和地图评分界面
  -> MainMenu
  -> 在线房间查看界面

在线房间查看界面 Esc
  -> MainMenu.Show
  -> Logo 入场动画
  -> 完整主菜单
```

普通本地地图和普通主菜单启动流程不在本问题范围内。

## 初始现象

从 Workshop 线上地图按 `Esc` 返回时，原生流程会先进入通关时间、地图评分和自定义战役相关界面，不能直接回到在线房间查看界面。

导航修复后，在线房间大厅可以正常打开，但从大厅返回主菜单时又出现以下界面问题：

- Logo 仍在播放入场动画时，主菜单文字已经提前出现。
- 部分情况下菜单文字整体向上，Logo 会遮挡文字。
- 部分中间状态只剩选中框，文字和其它按钮无法操作。
- 直接隐藏或重新激活菜单项会破坏原生菜单动画的显示时序。

## MCP 与源码定位

已确认从在线房间大厅返回主菜单的原生调用链：

```text
Lobby.GoBackToMainMenu
  -> MainMenu.Show
  -> MainMenu.ShowHideMenu
  -> MainMenu.ShowRoutine
```

反编译 `MainMenu+<ShowRoutine>c__Iterator2.MoveNext` 后确认关键顺序如下：

1. 设置 `InputReader.IsBlocked=true`。
2. 播放 Logo 和背景动画。
3. 将 Logo 和主菜单根 Transform 缩放到 `Vector3.zero`。
4. 设置 `Menu.MenuActive=true`，原生 setter 会重新激活菜单项、菜单高亮和菜单容器。
5. 等待 1 秒，然后用 `Time.deltaTime * 5` 将缩放从 0 插值到 1。
6. 动画结束后播放音效，并解除输入阻塞。

因此，问题不是单纯的菜单坐标计算错误。原生 `MenuActive=true` 会在 Logo 动画刚开始时重新打开菜单对象；只设置菜单项 GameObject 的 active 状态不能阻止子节点的文字 Renderer 被重新显示。

## 相关修复

### 线上地图直接返回大厅

在确认当前是有效 Workshop 线上会话、暂停状态为 `MenuPause` 或 `ConfirmationPause`，且目标场景为 `VictoryCustomCampaignSteam` 后：

- 将 `GameState.sceneToLoad` 改为 `MainMenu`。
- 清除 `loadCustomCampaign` 和 `immediatelyGoToCustomCampaign`。
- 跳过通关时间和地图评分界面。
- `MainMenu` 初始化完成后调用官方 `MainMenu.TryToGoToLobby(MultiplayerPlayMode.Online)`。

该路径只在有效 Workshop 线上会话启用，普通本地流程不修改。

### 主菜单初始化与大厅导航

- `MainMenu.DelayInitializeMenu` 的原生 3 秒等待只在普通启动时保留。
- 线上 Workshop Esc 返回路径将该次等待临时改为 0 秒。
- 初始化期间隐藏 Logo 和菜单视觉，但不禁用 `MainMenu` 根对象，避免中断原生初始化协程。
- 进入 `MainMenu` 后等待约 250ms，再尝试打开在线大厅。
- 导航失败至少等待 1 秒缓冲；最长等待 30 秒，失败后恢复完整主菜单视觉和输入。

### 大厅返回主菜单的动画显示

在 `Lobby.GoBackToMainMenu` 前：

- 恢复高亮索引和正常菜单间距。
- 不调用会立即移动高亮框、扰乱入场前布局的 `ResetHighlightIndex`。
- 暂存菜单项下每个 `Renderer.enabled` 的原始状态。
- 暂时隐藏菜单项、菜单高亮、菜单容器和所有子 Renderer。

在 `MainMenu.ShowRoutine` 运行期间：

- 对 `Menu.MenuActive=true` 增加只针对 `MainMenu` 返回路径的后置保护。
- 每一帧继续隐藏菜单项、菜单高亮、菜单容器和子 Renderer。
- 不修改 Logo 的原生缩放和动画时间。

在 `ShowRoutine` 完成后：

- 恢复菜单项、菜单高亮和菜单容器。
- 按暂存状态恢复每个 Renderer 的可见性。
- 解除输入阻塞。

这样文字只会在 Logo 入场动画完成后显示，且不会改变原生菜单布局坐标。

## 验证结果

用户已完成修复后的实机验证，确认：

- 地图内 `Esc` 可以按预期跳过通关时间和评分界面并进入在线房间查看界面。
- 从在线房间大厅返回主菜单时，文字不再提前出现。
- Logo 不再遮挡向上偏移的菜单文字。
- 不再出现只剩选中框且其它按钮无法操作的状态。
- 普通主菜单和本地地图流程未发现回归。

本次修复已包含在提交 `d63403f`（`修复在线大厅返回主菜单文字提前显示`）中。后续若修改返回动画或主菜单初始化时序，应重新验证上述完整流程。

## 独立问题

Workshop 地图自身可能出现 `GeneratePole.Awake -> Map.PlaceDoodad -> Map.LoadArea` 的 `NullReferenceException`。该地图对象异常与本次大厅导航、菜单动画和输入恢复问题相互独立，不能用它判断本次修复是否成功。

## 后续测试重点

1. 使用有效 Workshop 线上会话，从地图内按 `Esc`，确认不加载通关时间和地图评分界面。
2. 确认在线房间查看界面打开后，按 `Esc` 返回主菜单时 Logo 动画和文字显示顺序正确。
3. 在主菜单动画完成后操作上下和确认输入，确认菜单项全部可用。
4. 额外测试普通本地地图返回和普通启动，确认 Renderer 可见性状态没有泄漏到其它流程。
5. 若在线大厅打开失败，确认最长 30 秒后可以恢复完整且可操作的主菜单。
