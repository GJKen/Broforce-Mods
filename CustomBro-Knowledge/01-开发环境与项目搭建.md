# 开发环境与项目搭建

来源: [Setting Up a Development Environment](https://github.com/Gorzontrok/Bro-Maker/wiki/Setting-Up-a-Development-Environment) / [Using the broforce-tools Script](https://github.com/Gorzontrok/Bro-Maker/wiki/Using-the-broforce%E2%80%90tools-Script)

## 必装工具

- **Visual Studio 2022** — 安装时勾选 ".NET desktop development" 工作负载(**不是必须**,见下文「无 VS 纯命令行构建」;wiki 作者自己的习惯而已)
- **.NET Framework 3.5 SP1** — 编译自定义 bro 必须用它作为目标框架。Windows 10 自带 `C:\Windows\Microsoft.NET\Framework64\v3.5\csc.exe` 编译器,通常无需额外安装;若不存在再装官方运行库
- **dnSpy** — 反编译 `Assembly-CSharp.dll` 查看游戏源码(见 03 文档)
- **Unity Mod Manager (UMM)** — 通过 [r2modman](https://thunderstore.io/c/broforce/p/ebkr/r2modman/) 安装
- **BroMaker** / **RocketLib** — Thunderstore 上安装

可选但强烈推荐:
- **RuntimeUnityEditor** — 游戏内实时检视 GameObject/组件/变量(F12,建议改成 F11),详见 07 调试文档
- **Aseprite** — 画 / 改 spritesheet(本机在 `E:\Program\Aseprite\Aseprite.exe`)。**画贴图走它,不要写脚本生成**,见 [12 文档](12-用Aseprite画角色贴图.md)
- **UnityPy**(Python 库)— 从游戏的 assetbundle 导出原版 spritesheet 和音频。不需要 GUI 工具,**本机已有的导出成品在 `Broforce_src\GameAssets\`,脚本在 `templates\ExportGameSprites.py`**,见 [11 文档](11-导出官方贴图与资源包.md)

> 更新(2026-09-13):本节早期推荐过 **GIMP**(做 spritesheet)和 **AssetStudio**(提取原版素材),两个本机都**没装**,已分别由 Aseprite 与 UnityPy 取代。

## 方式一:broforce-tools 脚本(自动)

[Broforce-Templates](https://github.com/alexneargarder/Broforce-Templates) 提供 `bt` CLI:

```bash
pipx install path/to/Broforce-Templates/Scripts

bt create -t bro -n "Your Bro's Name" -a "Your Name"   # 交互式可不带参数
bt init-thunderstore "Your Bro's Name"                  # 后补 Thunderstore 元数据
bt package "Your Bro's Name"                            # 打包发布 zip(版本读自 Changelog.md)
bt changelog add "Your Bro's Name" "Fixed fire rate..." # 快速记录变更
bt unreleased                                           # 查看未发布的更改
```

`bt create` 会:复制 bro 模板并重命名 → 生成 `Changelog.md` → 拷贝 `BroforceModBuild.targets` → 可选配置 Thunderstore。

配置文件在 `%APPDATA%\broforce-tools\config.json`(`bt config init` 交互生成)。

## 方式二:手动建 VS 工程

1. VS 2022 → 新建项目 → **Class Library (.NET Framework)**(注意别选成 Visual Basic 同名模板)
2. 目标框架选 **.NET Framework 3.5**
3. 下载 [BroforceMods/libs](https://github.com/alexneargarder/BroforceMods/tree/master/libs) 里的 dll 放进仓库,Add Reference 引入:

   **必需:**
   - `0Harmony.dll`
   - `Assembly-CSharp.dll`(游戏本体代码)
   - `UnityEngine.dll`、`UnityEngine.CoreModule.dll`
   - `UnityEngine.IMGUIModule.dll`、`UnityEngine.TextRenderingModule.dll`
   - `UnityEngine.UI.dll`
   - `UnityModManager.dll`
   - `Newtonsoft.Json.dll`(BroMakerLib 依赖)
   - `BroMakerLib.dll`(在 BroMaker 的 Thunderstore 包里:本仓库 `E:\Study\C#\Bro-Maker\Release\BroMaker-BroMaker-2.6.2.zip` 内 `UMM\Mods\BroMakerLib\BroMakerLib.dll`;r2modman 安装的话在 `Mods\BroMaker-BroMaker\BroMakerLib\BroMakerLib.dll`,见下)

   其余 libs 里的(`Rewired_Core.dll`、`BitCode.dll`、`mcs.dll`、其他 UnityEngine 模块)按需添加。

4. 为了 IntelliSense 提示,把同名 `.xml` 文件放到 dll 旁边。**本机现成位置**(直接拷过去即可):

   | 文件 | 源码仓库里 | 已安装副本 |
   |---|---|---|
   | `BroMakerLib.xml` | `E:\Study\C#\Bro-Maker\BroMakerLib\_ModContent\` | `...\UMM\Mods\BroMaker-BroMaker\BroMakerLib\` |
   | `RocketLib.xml` | `E:\Study\C#\RocketLib\RocketLib\_ModContent\` | `...\UMM\Mods\RocketLib-RocketLib\RocketLib\` |

## 构建系统(自动安装到游戏)

`BroforceModBuild.targets`(本地示例: `E:\Study\C#\CustomBros\Scripts\BroforceModBuild.targets`)在每次 Build 时:
编译 → 把 dll 复制到内容文件夹 → 安装到 Broforce 的 `BroMaker_Storage` 文件夹。**不需要手动拷 dll。**

唯一要自己建的文件是仓库根目录的 `LocalBroforcePath.props`(本地示例: `E:\Study\C#\Bro-Maker\LocalBroforcePath.example.props`):

```xml
<Project>
  <PropertyGroup>
    <!-- REQUIRED: r2modman Broforce profile 的 UMM 文件夹 -->
    <BroforcePath>C:\Users\YourName\AppData\Roaming\r2modmanPlus-local\Broforce\profiles\Default\UMM</BroforcePath>

    <!-- 默认从游戏 Mods 文件夹找 BroMakerLib / RocketLib,从源码构建时改成源码路径 -->
    <BroMakerLibPath>$(BroforcePath)\Mods\BroMaker-BroMaker\BroMakerLib\BroMakerLib.dll</BroMakerLibPath>
    <RocketLibPath>$(BroforcePath)\Mods\RocketLib-RocketLib\RocketLib\RocketLib.dll</RocketLibPath>

    <!-- 可选构建开关 -->
    <!-- <CloseBroforceOnBuild>true</CloseBroforceOnBuild> -->
    <!-- <LaunchBroforceOnBuild>false</LaunchBroforceOnBuild> -->
    <!-- <UseHardLinksForInstall>false</UseHardLinksForInstall> -->
  </PropertyGroup>
</Project>
```

多个仓库可共享配置:在所有仓库的父目录放 `BroforceGlobal.props`,各仓库的 `LocalBroforcePath.props` 会自动导入并可覆盖。

VS Code 等无 .sln UI 的环境可用 Broforce-Templates 的 `Makefile.common`(`make build / clean / rebuild`);VS 里直接 Build Solution 即可。

## 无 VS 纯命令行构建(推荐给 AI 写码 + 脚本编译的工作流)

不需要 Visual Studio,也不需要 MSBuild 工程。Windows 自带的 .NET Framework 3.5 编译器直接编译即可:

```
C:\Windows\Microsoft.NET\Framework64\v3.5\csc.exe
```

参考本仓库 `CustomMapMultiplayer\BuildAndDeploy.ps1` 的做法(读 props 拿 dll 路径 → 收集 `src/*.cs` → `/reference:` 列表 → csc 编译 → 部署)。

自定义 bro 与普通 UMM mod 的差异:

1. **额外引用**:`BroMakerLib.dll`(必需)、`Newtonsoft.Json.dll`(BroMakerLib 依赖)
2. **部署目标**:不是 UMM `Mods\`,而是 `UMM\BroMaker_Storage\<BroName>\`
3. **不用 zip/Info.json**:走 BroMaker 的 `.mod.json` 体系(dll + bro json + 贴图放同一文件夹)

完整可用的脚本模板见 [`templates/BuildBro.ps1`](templates/BuildBro.ps1),props 模板见 [`templates/LocalBroforcePath.props.example`](templates/LocalBroforcePath.props.example)。

## Mods 文件夹在哪

所有已装 mod、自定义 bro、UMM 日志都在 r2modman profile 的 `UMM` 文件夹:

- **本机实际路径(认这个)**:`E:\Games\Broforce Mods\Broforce\profiles\Broforce\UMM\`
- r2modman **默认**路径(本机**没有**,别照着找):`%APPDATA%\r2modmanPlus-local\Broforce\profiles\Default\UMM\`
- Linux 默认:`~/.config/r2modmanPlus-local/Broforce/profiles/Default/UMM/`

> 本机 r2modman 把数据目录改到了 `E:\Games\Broforce Mods\`,profile 名是 `Broforce`(不是默认的 `Default`)。
> 换机器/重装时先确认实际路径,再照抄任何文档里的路径。

内部结构:
- `Mods\` — 每个 mod 一个 `Author-PackageName\` 文件夹(`BroMakerLib.dll`、`RocketLib.dll` 在这)
- `BroMaker_Storage\` — 自定义 bro:每个 bro 一个文件夹,含 `.dll`、`.mod.json`、`.json`、贴图
- `Core\Log.txt` — UMM 日志(实时刷新,VS Code 打开可实时看)
