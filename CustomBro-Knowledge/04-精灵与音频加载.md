## 通过 JSON parameters(推荐,自动加载)

主精灵、枪精灵、特技图标、头像、过场贴图都在 bro JSON 的 `parameters` 节配置,详见 06 文档:
`Sprite / GunSprite / SpecialIcons / Avatar` 等。

## 程序化加载:BroMakerLib.ResourcesController

源码:`E:\Study\C#\Bro-Maker\BroMakerLib\ResourcesController.cs`

```csharp
// Material(带缓存,respawn 不会重复读文件;默认 shader 为多数 Broforce 物体所用)
```

## 换精灵材质

改 Broforce 对象的精灵 = 换 MeshRenderer 的 material(**别用 sharedMaterial,会波及无关对象**):

```csharp
base.GetComponent<Renderer>().material = myCustomMaterialVariable;
```

## 透明像素

默认 shader `Unlit/Depth Cutout With ColouredImage` 不支持半透明(软边缘变黑)。两种方案:

**方案一:换 shader** —— `Unlit/Depth Cutout With Image` 支持半透明 alpha,但不支持 tint(无敌闪白等失效):

```csharp
var mat = ResourcesController.CreateMaterial(
    Path.Combine( yourBroFolder, "YourSprite.png" ),
    ResourcesController.Unlit_DepthCutoutImage );
```

**方案二:改 GameObject 层** —— 层 5、19、28 支持透明。层 19 最实用(5 和 28 会画在草、桥栏杆等前面);保留 tint 功能但改变与世界的遮挡顺序。

## 持续播放音频(火焰喷射/质子枪等)

```csharp
// 声明为 public 字段(prefab 序列化需要)
public AudioSource continuousAudio;

// AfterPrefabSetup() 里配置
this.continuousAudio = base.gameObject.AddComponent<AudioSource>();
this.continuousAudio.rolloffMode = AudioRolloffMode.Linear;
this.continuousAudio.minDistance = 200f;
this.continuousAudio.maxDistance = 500f;
this.continuousAudio.spatialBlend = 1f;
this.continuousAudio.volume = 0.33f;

// 启动循环
if ( !this.continuousAudio.isPlaying )
{
    this.continuousAudio.clip = myLoopSound;
    this.continuousAudio.loop = true;
    this.continuousAudio.Play();
}

// Update 里停止(上直升机或死亡)
if ( this.isOnHelicopter || this.actionState == ActionState.Dead )
{
    this.continuousAudio.enabled = false;
}
```

## 预加载

在 `PreloadAssets()` 里预读避免 spawn 卡顿:

```csharp
public override void PreloadAssets()
{
    string directoryPath = Path.GetDirectoryName( Assembly.GetExecutingAssembly().Location );
    CustomHero.PreloadSprites( directoryPath, new List<string> { "spriteStealth.png", "avatarStealth.png" } );
    CustomHero.PreloadSprites( Path.Combine( directoryPath, "projectiles" ), new List<string> { "TranqDart.png" } );
    CustomHero.PreloadSounds( Path.Combine( directoryPath, "sounds" ), new List<string> { "gun1.wav" } );
}
```

## 在 Start() 里建额外的动画精灵对象(来自 Drunken Broster 模式)

```csharp
gunSpriteMelee = new GameObject( "GunSpriteMelee",
    new Type[] { typeof( MeshFilter ), typeof( MeshRenderer ), typeof( SpriteSM ) } ).GetComponent<MeshRenderer>();
gunSpriteMelee.transform.parent = this.transform;
gunSpriteMelee.gameObject.SetActive( false );
gunSpriteMelee.material = ResourcesController.GetMaterial( directoryPath, "gunSpriteMelee.png" );
gunSpriteMeleeSprite = gunSpriteMelee.gameObject.GetComponent<SpriteSM>();
gunSpriteMeleeSprite.RecalcTexture();
gunSpriteMeleeSprite.SetTextureDefaults();
gunSpriteMeleeSprite.lowerLeftPixel = new Vector2( 0, 32 );
gunSpriteMeleeSprite.pixelDimensions = new Vector2( 32, 32 );
gunSpriteMeleeSprite.plane = SpriteBase.SPRITE_PLANE.XY;
gunSpriteMeleeSprite.width = 32;
gunSpriteMeleeSprite.height = 32;
gunSpriteMeleeSprite.transform.localPosition = new Vector3( 0, 0, -0.9f );
gunSpriteMeleeSprite.CalcUVs();
gunSpriteMeleeSprite.UpdateUVs();
gunSpriteMeleeSprite.offset = new Vector3( 0f, 15f, 0f );
```
