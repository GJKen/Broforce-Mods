# 最小可运行角色与文件结构

来源: [Manual Setup](https://github.com/Gorzontrok/Bro-Maker/wiki/Manual-Setup) / [Creating a Mod File](https://github.com/Gorzontrok/Bro-Maker/wiki/Creating-a-Mod-File) / [Creating a New Custom Bro](https://github.com/Gorzontrok/Bro-Maker/wiki/Creating-a-New-Custom-Bro)

## 最小代码

```csharp
using BroMakerLib;
using BroMakerLib.CustomObjects.Bros;

namespace Bro_Template
{
    [HeroPreset( "Bro Template", HeroType.Rambro )]
    public class BroTemplate : CustomHero
    {
    }
}
```

- `[HeroPreset(名字, HeroType)]` 第一个参数是**自定义 preset 名**,必须和 bro JSON 里的 `characterPreset` 完全一致——这是两者关联的唯一纽带。
- 第二个参数 `HeroType.Rambro` 决定 BroMaker 从哪个原版 bro 复制默认值,选谁都行(Gorzontrok 几乎都用 Rambro),所有默认值之后都能改。
- 空类的行为 = 完整的 Rambro(主武器/特技/近战全套)。

## bro JSON(角色定义)

放进 `BroMaker_Storage` 下自建的 bro 文件夹(名字任意,建议和 bro 同名):

```json
{
  "name": "Bro Template",
  "characterPreset": "Bro Template",
  "parameters": {
    "BetterAnimation": true,
    "Sprite": "sprite.png",
    "GunSprite": "gunSprite.png",
    "SpecialIcons": "special.png",
    "Avatar": "avatar.png"
  },
  "cutscene": {
    "heading": "Bro Template",
    "subtitle1": "Joins the Battle!",
    "headingScale": 0.14,
    "spriteRect": { "x": 0, "y": 256, "width": 256, "height": 256 },
    "spritePath": "cutscene.png",
    "anim": "Intro_Bro_Rambro",
    "playCutsceneOnFirstSpawn": true
  },
  "beforeAwake": { "speed": 130, "fireRate": 0.1, "canChimneyFlip": true, "originalSpecialAmmo": 1 },
  "afterAwake": {},
  "beforeStart": {},
  "afterStart": {}
}
```

要点:
- `characterPreset` 必须匹配 `[HeroPreset]` 的字符串。
- `parameters` 只放贴图/UI 类参数(完整表见 06 文档);`before/after Awake/Start` 四个节放 bro 类的普通字段赋值。
- JSON 文件名任意,但 `.mod.json` 的 `CustomBros` 里要指向它。
- 没画好贴图时可删掉贴图行,或用 [Broforce-Templates 的占位图](https://github.com/alexneargarder/Broforce-Templates/tree/master/Scripts/Bro%20Template)。

## mod 文件(`.mod.json`,后缀必须精确是 `.mod.json`)

```json
{
  "Version": "1.0.0",
  "BroMakerVersion": "2.6.0",
  "Name": "Bro Template",
  "Author": "yourname",
  "CustomBros": [ "Bro Template.json" ],
  "Assemblies": [ "Bro Template.dll" ]
}
```

| 字段 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `Name` | string | ✅ | mod 名 |
| `Version` | string | ✅ | mod 版本 |
| `BroMakerVersion` | string | ✅ | 要求的最低 BroMaker 版本(设成你开发时用的版本;低于它的 bro 会被拒绝加载) |
| `Author` | string | ✅ | 作者 |
| `Assemblies` | string[] | ❌ | 相对 mod 文件夹的 dll 路径 |
| `CustomBros` | string[] | ✅ | 相对 mod 文件夹的 bro JSON 路径(子文件夹写 `subfolder/MyBro.json`) |
| `Abilities` | string[] | ❌ | 能力 JSON 路径(纯代码实现能力则不需要) |

## 文件夹最终结构

```
BroMaker_Storage\
  Bro Template\
    Bro Template.mod.json   ← BroMaker 从这里开始找
    Bro Template.json       ← bro 定义
    Bro Template.dll        ← 编译产物(构建系统自动复制)
    sprite.png / gunSprite.png / special.png / avatar.png / cutscene.png
```

本地真实例子:`E:\Study\C#\CustomBros\Bronobi\Bronobi\_Mod\`(含 `gz.bronobi.mod.json`、`Bronobi.json`、全部 png/wav)。

之后启动游戏,BroMaker 菜单里就能看到角色;进关卡点击角色 → "Switch to Bro" 切换。
