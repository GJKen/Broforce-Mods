# 类结构与核心方法重写

来源: [Overriding Methods](https://github.com/Gorzontrok/Bro-Maker/wiki/Overriding-Methods-to-Add-New-Functionality) / [Glossary of Important Methods](https://github.com/Gorzontrok/Bro-Maker/wiki/Glossary-of-Important-Methods)

## 类继承体系

```
TestVanDammeAnim (角色通用逻辑, Mook 敌人也继承自它)
  └─ BroBase (玩家角色特有, 内置 Rambro 全套动作)
      └─ CustomHero (BroMaker 提供, 自定义 bro 的基类)
          └─ 你的 BroXxx
```

- **BroBase** 的默认行为就是 Rambro 的 Primary/Special/Melee 全套(Rambro 类本身几乎不重写任何方法,代码都在基类里)。
- 继承 `CustomHero` 即获得全部默认行为;想自定义就重写 `BroBase`/`TestVanDammeAnim` 的方法:

```csharp
protected override void Awake()
{
    // 你的代码
    base.Awake();
}
```

- 添加新能力时,先在原版代码(dnSpy 看 `Assembly-CSharp.dll`)或现有自定义 bro 源码里找相似能力抄改。
- 直接读源码:`E:\Study\C#\Bro-Maker\BroMakerLib\CustomObjects\Bros\CustomHero.cs`

## 生命周期与 BroMaker 特有方法

### Unity 方法

- **`Awake()`** — 创建时最先调用。可初始化变量/弹射物,但**此时 BroMaker 还没加载 sprite/gunSprite/avatar 材质**——想缓存这些材质要放 `Start()`。
- **`Start()`** — 推荐 main 初始化点:额外精灵、弹射物 prefab、缓存原版材质。
- **`Update()`** — 每帧。重写时在 `base.Update()` 后加 `if (acceptedDeath) return;` 跳过死亡状态的逻辑。
- **`OnDestroy()`** — 清理不想在死后残留的对象。

### BroMaker 方法

- **`PreloadAssets()`** — mod 启动加载时调用。预加载 sprite/音频避免 spawn 卡顿:
  ```csharp
  CustomHero.PreloadSprites( directoryPath, new List<string> { "spriteStealth.png", ... } );
  CustomHero.PreloadSounds( directoryPath, new List<string> { "gun1.wav", ... } );
  ```
  (JSON 里指定的贴图会自动加载,不需要手动。)
- **`BeforePrefabSetup()`** — 设置音效来源:
  ```csharp
  this.SoundHolderHeroType = HeroType.BroLee;                 // 主/特技/近战音效
  this.SoundHolderVoiceType = SoundHolderVoiceTypes.MaleLight; // 语音(优先级最高)
  ```
  都不设则用 `[HeroPreset]` 里的 HeroType;只设 HeroType 则音效+语音都用它。
- **`AfterPrefabSetup()`** — 预制体生成后调用(prefab 只在首次 spawn 生成,之后用缓存)。加载音频等资产。**这里加载的资产必须赋给 public 字段**(或 `[SerializeField]`),否则实例化时是 null。`PrefabSetup()` 会填好 `this.directoryPath`。
- **`HarmonyPatches(Harmony harmony)`** — 给 bro 挂 Harmony 补丁(修改敌人行为时用):`harmony.PatchAll(Assembly.GetExecutingAssembly());`
- **`UIOptions()`** — 在 BroMaker 菜单显示自定义选项(用 UMM 的 GUILayout API)。**选项界面用的是新实例,不是游戏内的 bro 实例**,要用 static 变量传递。配合 `[SaveableSetting]` 可持久化。
- **`GetVariant()`** — 控制变体选择;配合 `deduplicateVariants = true` 和 `GetUniqueVariant(allowedVariants)`。

### CustomHero 自动管理的开关(Awake/Start 前设置)

| Flag | 默认 | 作用 |
|---|---|---|
| `trackDeathRevival` | true | 跟踪死亡状态,自动调 `OnDeath()`/`OnRevived()`,维护 `acceptedDeath` |
| `trackInvulnerabilityTint` | true | 无敌结束后自动重置 `_TintColor`(渲染器/枪精灵/注册材质) |
| `useCustomMelee` | false | 自动设 `MeleeType.Custom`,启用自定义近战 |
| `blockGesturesDuringMelee` | true | 近战期间屏蔽 flex 动作 |
| `deduplicateVariants` | false | 多人时保证各实例变体不重复 |

### 死亡/复活

- `OnDeath()` / `OnRevived()` — 重写时**必须调 `base`**;做清理(停音效)/恢复(回弹药)。
- 自己的 `Update()` 里 `base.Update()` 后 `if (acceptedDeath) return;`。

### 无敌 tint

- 额外材质要 `RegisterTintMaterial(mat)`(一般在 `Start()` 里),否则无敌结束后会残留染色。
- `ResetTintColors()` 可手动重置。

## 主武器(Primary)调用链

```
按下开火 → StartFiring()   (fireCounter = fireRate < 0.3f ? fireRate : 0,快射速可瞬间开火)
每帧     → RunFiring()     (fireCounter += this.t; 达到 fireRate 时调 UseFire())
         → UseFire()       (取消近战 → FireWeapon() → PlayAttackSound())
松开     → StopFiring() (死亡/冻结/钉住时不调) 与 ReleaseFire() (无这些检查)
枪动画   → RunGun() → SetGunSprite(frame, row)
         → SetGunPosition(x, y) 每帧定位枪精灵
```

- **`UseFire()`** — 按状态决定弹射点/弹种(上挂、抓钩、贴墙、下蹲各有偏移);`Map.DisturbWildLife(...)` 惊动动物。
- **`FireWeapon(x, y, xSpeed, ySpeed)`** — 设 `gunFrame`、枪口火光、生成弹射物。典型生成:`ProjectileController.SpawnProjectileLocally(prefab, this, x, y, xSpeed, ySpeed, base.playerNum)`,弹速惯例 `base.transform.localScale.x * 400 + this.xI / 2`,枪口位置 `base.X + base.transform.localScale.x * 8~12f, base.Y + 8~10f`,`EffectsController.CreateMuzzleFlashEffect(...)`。
- **`RunGun()`** — `gunCounter > 0.0334f` 一帧,`gunFrame` 递减到 0;可用来做自定义枪动画/切枪动画。
- **`SetGunSprite(int spriteFrame, int spriteRow)`** — 别手动 `SetLowerLeftPixel`,它内置了吊索单手帧偏移(`gunSpriteHangingFrame`,默认 6)。
- `ActivateGun()/DeactivateGun()` 显隐枪精灵;`SetGunPosition` 一般不重写,调偏移用 `GunSpriteOffset` 参数。

## 近战(Melee)调用链

```
按近战 → StartMelee() → (meleeType 分派) StartKnifeMelee / StartPunch / StartCustomMelee
doingMelee 期间: AnimateCustomMelee() 每帧变帧 + RunCustomMeleeMovement() 每帧移动
AnimateCustomMelee 默认 → AnimateKnifeMelee() (伤害帧默认第3帧 → PerformKnifeMeleeAttack())
结束/中断 → CancelMelee() (重置变量, doingMelee = false)
```

- 启用自定义近战:`useCustomMelee = true`(Awake 里或 `base.Start()` 前),`Start()` 会自动把 `meleeType` 设为 `MeleeType.Custom` → 按近战时走 `StartCustomMelee()`。
- **`StartMelee()` 注意**:站在猪上会无视 `meleeType` 强制 Knife(猪滑),所以 spritesheet 上最好保留 knife 动作帧。
- **`AnimateCustomMelee()`** — 自己写动画+伤害逻辑。伤害套路(来自 Brostbuster):
  ```csharp
  Map.DamageDoodads( 3, DamageType.Knock, base.X + base.Direction * 4, base.Y, 0f, 0f, 6f, base.playerNum, out flag, null );
  this.KickDoors( 24f );
  if ( Map.HitClosestUnit( this, base.playerNum, 4, DamageType.Knock, 14f, 24f,
        base.X + base.transform.localScale.x * 8f, base.Y + 8f,
        base.transform.localScale.x * 200f, 500f, true, false, base.IsMine, false, true ) )
  {
      this.meleeHasHit = true;
  }
  this.TriggerBroMeleeEvent();
  ```
- **`RunCustomMeleeMovement()`** — 建议从 `RunKnifeMeleeMovement()` 抄改。
- **近战允许跳**:重写 `Jump(bool wallJump)`,若 `doingMelee` 则 `jumpingMelee = true; dashingMelee = false;`。防二段跳:`CancelMelee()` 里 `jumpTime = 0f;`。

## 特技(Special)调用链

```
按特技 → PressSpecial() (检查酸蚀/近战, 设 usingSpecial = true, frame = 0)
每帧变帧 → AnimateSpecial() → 到投掷帧(默认2)调 UseSpecial()
UseSpecial() → SpecialAmmo > 0 ? 执行特技(默认丢 specialGrenade, 弹药-1) : HeroController.FlashSpecialAmmo(playerNum) 红闪
```

- **`PressSpecial()`** — 想没弹药时不播动画就把检查挪进来;也可用于初始化特技变量。
- **`AnimateSpecial()`** — 自定义动画帧数/帧率/触发帧;常用 `this.sprite.SetLowerLeftPixel(...)`、`this.usingSpecialFrame`。
- **`UseSpecial()`** — 完全自定义特技效果(buff、载具、任意弹射物)。
- **防墙跳重置特技动画**:用独立的帧计数器(见 07 FAQ)。

## 动画

- **`ChangeFrame()`** — 动画状态分派器(调 AnimateIdle/Running/Melee/Special 等)。**加全新动画状态时重写它**;改已有能力的动画去重写对应的 Animate 方法:
  ```csharp
  protected override void ChangeFrame()
  {
      if ( this.attackStationary ) this.AnimateAttackStationary();
      else if ( this.attackUpwards ) this.AnimateAttackUpwards();
      else if ( this.attackDownwards ) this.AnimateAttackDownwards();
      else if ( this.attackForwards ) this.AnimateAttackForwards();
      else base.ChangeFrame();
  }
  ```
- **`SetGestureAnimation(GestureElement.Gestures)`** — flex 动作(枚举值 None/Salute/Wave/Point/Flex/Thrust/KneeDrop/Shhh/HighFive,实际只实现了 Flex)。重写可在 flex 时释放抓取物等。

## 实用小知识

- 检查在直升机上:`this.isOnHelicopter`。
- 按资源名拿原版预制体:`InstantiationController.GetPrefabFromResourceName("themeholders:Themeholder Jungle")`;ThemeHolder 也可走 `Map.Instance`。
- 调私有方法/字段用反射并缓存 `MethodInfo`/`FieldInfo`:
  ```csharp
  typeof(TestVanDammeAnim).GetMethod( "Gib", BindingFlags.NonPublic | BindingFlags.Instance )
      .Invoke( targetObject, new object[] { DamageType.InstaGib, 0f, 0f } );
  ```
- 自定义按键(RocketLib):
  ```csharp
  public static KeyBindingForPlayers switchWeaponKey = AllModKeyBindings.LoadKeyBinding( "Furibrosa", "Switch Weapon" );
  // Update 里: switchWeaponKey.IsDown( playerNum ) / PressedDown( playerNum ) —— 无需自行校验 playerNum
  // UIOptions 里: switchWeaponKey.OnGUI( out _, ( GUI.tooltip == string.Empty ) );
  ```
- 避免改 `sharedMaterial`(会影响其他对象),用 `GetComponent<Renderer>().material = ...`。
