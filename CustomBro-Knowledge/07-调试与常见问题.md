## BroMaker 日志

```csharp
using BroMakerLib.Loggers;
BMLogger.Log( "Hello World!" );
```

日志出现在游戏内 UMM 窗口的 Logs 标签,以及 UMM 目录下的 `Core\Log.txt`(实时刷新,用 VS Code 打开可边玩边看)。

**本机实际路径**:`E:\Games\Broforce Mods\Broforce\profiles\Broforce\UMM\Core\Log.txt`
(文档里常见的 `%APPDATA%\r2modmanPlus-local\...\profiles\Default\...` 是 r2modman 默认值,**本机没有**,实际数据目录改到了 `E:\Games\Broforce Mods\`,profile 名是 `Broforce`;详见 01 文档「Mods 文件夹在哪」。)

## RuntimeUnityEditor(强烈推荐)

- 下载 UMM 版,像普通 mod 一样装;游戏内 **F12** 打开(建议改 F11,F12 是 Steam 截图键)
- **Object Browser**:游戏内**中键点击**对象(middle-click 多次可在鼠标下的多个对象间轮换)列出其组件;主组件就是 bro 的类
- **Inspector**:实时查看/修改变量、调用方法(如直接改 `fireRate` 不用重开游戏)
- **时间控制**:底部栏 暂停/继续、游戏速度 0.5x~2x——调高速弹射物、慢放动画验证帧时非常有用;暂停后中键检查并改值

## RocketLib DrawDebug(可视化调试)

```csharp
using RocketLib.Utils;

// 首参是 ID:同 ID 每帧调用会更新已有图形而非新建
DrawDebug.DrawLine( "myLine", startPosition, endPosition, Color.red, 0.3f );
DrawDebug.DrawRectangle( "myRect", corner1, corner2, Color.green, 0.3f );   // 两对角
DrawDebug.DrawCrosshair( "myCrosshair", center, 10f, Color.yellow, 0.3f ); // 10f = 长度
```

需要引用 `RocketLib.dll`(源码在 `E:\Study\C#\RocketLib\`)。

## UIOptions() 当调试台

BroMaker 菜单里的选项在游戏运行时显示 → 可加实时滑条/开关测试数值,配合 `[SaveableSetting]` 持久化,免重编译。注意:选项界面是**新实例**,传值要 static。

## 常见问题速查(FAQ 精选)

| 问题 | 方案 |
|---|---|
| 头像/特技图标没生效 | 放 `parameters` 节(不是 before/after 节) |
| disarmed 等其他贴图 | 是 bro 类普通字段,放 `afterAwake` 等:`"disarmedGunMaterial": "x.png"` |
| 半透明像素发黑 | 换 `Unlit_DepthCutoutImage` shader 或改 layer 5/19/28(19 最稳) |
| 变体多人重复 | `deduplicateVariants = true`(Awake);过滤用 `GetUniqueVariant(allowed)` |
| 死后逻辑还在跑 | `Update()` 里 `base.Update()` 后 `if (acceptedDeath) return;` |
| 死后音效/状态残留 | 重写 `OnDeath()` 做清理(`OnRevived()` 恢复),必调 `base` |
| 无敌 tint 残留在额外材质 | `Start()` 里 `RegisterTintMaterial(mat)`;急用可 `ResetTintColors()` |
| 特技动画被墙跳/爬墙重置 | 用独立帧计数器:重写 `IncreaseFrame()`,`usingSpecial` 时 `++usingSpecialFrame`,AnimateSpecial 用该计数器(不用 base.frame) |
| 近战被 flex 重置 | `blockGesturesDuringMelee = true` 已自动处理(默认开) |
| 近战想允许跳跃 | 重写 `Jump(bool)`:doingMelee 时 `jumpingMelee = true; dashingMelee = false;` |
| 近战跳后能再蓄力跳 | `CancelMelee()` 里 `jumpTime = 0f;` |
| 穿透弹秒杀 Boss | 命中时 `if ( BroMakerUtilities.IsBoss( unit ) ) Death();`(Boss = 多段 BossBlockPiece) |
| 弹射物不下坠 | 继承 CustomGrenade,或 `Update` 里 `yI -= 500f * t` |
| 特技没弹药时仍播动画 | 弹药检查默认在 `UseSpecial()`;想提前拦截就重写 `PressSpecial()` |
| 站猪上近战变刀 | `StartMelee()` 硬编码(猪滑),spritesheet 保留 knife 帧 |
| Unity 日志被掩埋 | 所有自定义类加 `using BroMakerLib.Loggers;` 用 BMLogger |
| JSON 变量节留空以为吃原版默认 | 不会!`fireRate` 等落 0 → 每帧开枪;在乎的字段必须显式写(见 10 文档) |
| gunSprite 重画后手臂消失/抽搐 | 各帧含持枪手臂姿势,只能换色/改枪身像素,不能整帧重画(见 10 文档) |
| csc 3.5 报 CS1056 "$" / CS1501 默认参数 | 3.5 只支持 C#3:禁 `$"插值"`、禁省略可选参数,全部显式传参(见 10 文档) |
| CS0246 RaycastHit / 找不到类型 | 补引 `UnityEngine.PhysicsModule.dll`;API 签名用 PowerShell 反射 Assembly-CSharp 核实(见 10 文档) |
| 部署后弹射物贴图 404/不显示 | 贴图在 `_Mod\projectiles\` 子目录时部署必须递归复制(BroTemplate 版 BuildBro.ps1 已支持) |
| 弹射物sprite字段不存在 | Projectile 基类无公开 sprite 字段,自己 `GetComponent<SpriteSM>()` 缓存(BootKnife 同款) |
