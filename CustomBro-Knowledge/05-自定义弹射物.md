# 自定义弹射物

来源: [Creating Custom Projectiles](https://github.com/Gorzontrok/Bro-Maker/wiki/Creating-Custom-Projectiles)

## 三大弹射物类

| 类 | 特点 |
|---|---|
| `Projectile` | 所有子弹类弹射物的基类;默认命中即销毁,可改成穿透 |
| `Grenade` | **不继承 Projectile**。有颜色轨迹、爆炸前闪烁、可被扔回(均可改) |
| `SachelPack` | 继承 `Projectile`,附加粘附敌人/墙壁的逻辑 |

BroMaker 提供的包装类(源码:`E:\Study\C#\Bro-Maker\BroMakerLib\CustomObjects\Projectiles\`):
`CustomProjectile` / `CustomGrenade` / `CustomSachelPack` / `CustomPockettedSpecial`。
不是必须用——直接继承原版类抄改也行,但要自己补上 BroMaker 包装类做的事。

## 定义弹射物类

```csharp
using BroMakerLib.CustomObjects.Projectiles;

class YourProjectileClass : CustomProjectile
{
    protected override void Awake()
    {
        base.Awake();
    }
}
```

默认约定:贴图在 bro 文件夹下的 `projectiles/` 子目录,文件名 = 类名 `.png`。可覆盖:

```csharp
protected override void Awake()
{
    this.spriteFolder = "folderwithmysprites";
    this.spriteFileName = "mysprite.png";
    base.Awake();
}
```

CustomProjectile 会按贴图实际尺寸自动设宽高/像素尺寸;**多帧贴图必须自己设**:

```csharp
// 假设每帧 16x16
this.spriteHeight = 16;
this.spriteWidth = 16;
this.spriteLowerLeftPixel = new Vector2( 0, 16 );
this.spritePixelDimensions = new Vector2( 16, 16 );
```

`spriteWidth/Height` 也可以设成非贴图尺寸来放大/缩小显示。

## 创建 Prefab

在 bro 的 `Awake()`/`Start()` 里创建并缓存(prefab 自动进缓存,不会重复创建):

```csharp
this.yourProjectilePrefab = CustomProjectile.CreatePrefab<YourProjectileClass>();
// 手雷类:
this.yourGrenadePrefab   = CustomGrenade.CreatePrefab<YourGrenadeClass>();
```

## 生成弹射物

```csharp
this.yourProjectilePrefab.SpawnProjectileLocally( this, x, y, xSpeed, ySpeed, base.playerNum );
```

- 坐标惯例:`base.X + base.transform.localScale.x * 10f, base.Y + 8f`
- 速度惯例:`base.transform.localScale.x * 300f, 100f`
- 加散布:`ySpeed` 传 `(float)UnityEngine.Random.Range( -20, 20 )`
- 也可走原版:`ProjectileController.SpawnProjectileLocally( prefab, this, x, y, xSpeed, ySpeed, base.playerNum )`

## 命中框与物理

- **命中框**:`this.projectileSize = 10f;`(碰撞半径)。`horizontalProjectile`(默认 true)决定水平射线检测方式;`isWideProjectile`(默认 false)供超宽弹双段检测。>20 单位的大弹需自定义碰撞代码。
- **重力**:默认无重力。要么继承 `CustomGrenade`(自带重力),要么手动:
  ```csharp
  protected virtual void ApplyGravity() { this.yI -= 500f * this.t; }  // 500 为常规重力
  protected override void Update() { this.ApplyGravity(); base.Update(); }
  ```
- **穿透弹防秒 Boss**:Boss 由多段 `BossBlockPiece` 组成,穿透会对每段全额伤害。命中 `BroMakerUtilities.IsBoss( firstUnit )`(需 `using BroMakerLib;`)时调用 `Death()` 自毁。

## 保存设置(FAQ 补充)

```csharp
[SaveableSetting]
public static bool doubleTapSwitch = true;
```

在继承 `CustomHero` 的类的**可序列化 static 变量**上加 `[SaveableSetting]`:mod 启动自动加载,UMM 窗口按 Save 或游戏正常退出时自动保存(强退可能丢失)。配合 `UIOptions()` 展示。
