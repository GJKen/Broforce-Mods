# 未完成地图加载后加入官方房卡在主菜单

日期：2026-11-09。修复版本：BroforceBugFix 0.3.0。

## 原始现场与边界

5700G 加入端禁用 CustomMapMultiplayer，加入本机 JKChan 创建的官方 VIETNAM 房间失败。Steam 大厅已有双方，加入端仍在 MainMenu，玩家身份表为 0，`Networking.Networking.PauseStream=True`，`loadCustomCampaign=True`，旧 Workshop ID 为 `3781818421`。游戏版本一致。

最初那次 Workshop 请求由什么操作发起，现存日志不足以确定。此前手动解除暂停后，积压的 Aquabro 实例化消息在 MainMenu 解析，因 HeroController 尚未存在而发生空引用；这是积压消息的次生问题，不能据此认定 Aquabro 导致首次加入失败。

## 受控复现

1. 重启加入端，保持 CustomMapMultiplayer 禁用；确认 MainMenu、PauseStream=false、自定义地图字段为空。
2. 加入官方 VIETNAM 房间成功。按 fire 加入本地角色后，双端均为 2 名 Aquabro，加入端有本地角色。正常回主菜单也会解除暂停。
3. 加入端通过原生 CreateMatch 建立临时线上会话，从 MainMenu 调用 GameState.LoadLevel，使用原现场 Workshop ID 及 loadCustomCampaign=true、CurrentCampaign=null。此步骤主动设置了地图加载请求，用于复现相同生命周期；没有直接修改 PauseStream。
4. 原生地图请求结束后仍停在 MainMenu，下载进度为空，PauseStream=true、自定义地图字段保留。
5. 调用原生 SteamLayer.JoinLobby 加入官方房间；修复前仍为 PauseStream=true、身份表为 0，不能进入地图。

## 调用链与修复

- `GameState.LoadLevel` 在线上调用 InitiateHandshakeForConnection，随后 PauseStream=true，再进入异步 SteamController.LoadLevel。
- 只有场景到达 OnStart.Start -> Connect.AllDeterminsiticObjectsHaveBeenRegistered 才会解除暂停。未完成的 Workshop 流程没有到达该位置。
- `ConnectionLayer.JoinLobby -> DestroyLobby -> Connect.Disconnect` 清理旧房间，但没有解除静态 PauseStream；新房间的 RegisterPlayerID / SetServerID 仍被 RPCController.ProcessRPCQueue 阻塞。
- `LobbyJoinStreamFix` 在基类 JoinLobby 完成旧房间清理之后，仅在 MainMenu 且消息流仍暂停时调用 RPCController.Instance.Reset，再解除暂停，避免直接执行旧房间积压消息。新房主的 GameState 随正常握手更新旧地图字段。

补丁不依赖 CustomMapMultiplayer。现有主开关及新增独立开关 `EnableLobbyJoinStreamFix` 控制安装和卸载；只修复开始新房间时的残留暂停，不修复 Workshop 下载本身。

## 验证

- .NET Framework 3.5 构建通过，0.3.0 安装包及双端 UMM 已部署；部署前已终止并确认双端游戏退出。初次编译因 C# 3 编译器不支持省略 Harmony API 的可选参数而失败，补齐实参后通过。
- 重启后加入端日志确认 BroforceBugFix 0.3.0 启用、CustomMapMultiplayer disabled，运行时也没有加载后者程序集。
- 再次走相同原生 Workshop 加载路径，得到 MainMenu、PauseStream=true、loadCustomCampaign=true、旧 ID 保留。
- 原生 JoinLobby 调用前后输出分别为 `pause=True` 和 `pause=False`；追踪堆栈明确由 BroforceBugFix.LobbyJoinStreamFix.JoinLobbyPostfix 解除暂停。
- 加入新官方房间 `109775243946773097` 后，双端均为 Test Evan2 / VIETNAM，玩家数均为 2，各自有一个本地 Aquabro；加入端 PauseStream=false、自定义地图标记为 false、旧 ID 清空、身份表为 2、CMM=false。
- 本轮成功加入日志没有 Aquabro Resolve failed 或 NullReferenceException；清理旧队列后未再触发首次排查中手动解冻积压消息产生的角色空引用。
- 临时 trace-native-join 和 join-official 脚本已卸载。本轮启动的双端游戏验证后关闭。

上述验证记录包含加入前、JoinLobby 即时输出及双端最终状态；原始结果附件仅在本地保留，存放于 `docs/evidence/2026-11-09-lobby-join-stream/`，不把原始附件混入问题记录目录。按用户要求，已删除本轮临时脚本、日志副本和旧版 DLL / Info.json 备份。

离线评估：补丁仅挂在 JoinLobby，且要求 MainMenu 和已暂停；不进入联机加入流程的离线关卡不执行该补丁。本轮不重做既有爆炸箱修复验收。
