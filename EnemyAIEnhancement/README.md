# EnemyAIEnhancement

Broforce 敌人 AI 增强插件，当前版本 **0.19.4**。支持单机、本地多人及联机；增强决策由实际拥有端执行，动作、武器和伤害继续使用原生流程。

当前实现覆盖已检查的 Utility Mod「Spawn Enemy」66个菜单项中的59项，其余7项不适用。覆盖数表示实现范围，不表示每项都完成所有方向和自然阶段的联机验证。具体范围见 [验证说明](docs/VALIDATION.md)。

## 游戏内的变化

| 敌人类别 | 增强行为 |
| --- | --- |
| 普通枪兵、强壮枪兵、科学家 | 记忆最后看见的位置，沿可达路线追击、绕障及搜索；射路受阻时有限调整站位 |
| 火箭兵、榴弹兵、盾牌兵 | 火箭兵保持发射距离；榴弹兵后撤并检查投掷净空；盾牌兵面向威胁接近和守位 |
| 壮汉、机甲、自爆兵、亡灵 | 在原生攻击周期之间改善接近和转向；保留完整连射、自爆引信、跳扑及复活阶段 |
| Scout、Treasure、Ninja | 优先选择可达逃跑点；忍者在原生揭示、跳出和落地后才进行增强决策 |
| 喷气兵 | 根据可见威胁调整短程空中位置，保留原生喷气、武器与恢复阶段 |
| 蛇、抱脸虫、异形、狗及地狱犬 | 检查身体通路、落脚与攻击净空，改善接近、转向和近身攻击机会 |
| Warlock、Boomer、Executioner | 改善施法、喷吐和火墙机会；保留原生传送门、召唤、整轮攻击和冷却 |
| Lost Soul、Screecher、Baneling及近身组 | 根据可见观察进行有限拦截，保留原生俯冲、引信和爆炸阶段 |
| 精英、将军、报警兵 | 保留原生技能轮换和召援；同拥有端友军有限共享亲眼观察的信息，并协调站位 |
| 武装载具、运输载具 | 改善周期瞄准、部署机会及安全停车点；保留原生行车方向、投兵数量和武器节奏 |
| 战斗蠕虫、六种 Boss | 在原生阶段允许时使用可见观察、有限领先和周期锁点，保留原生阶段与攻击责任 |

默认目标记忆6秒，追击边界为出生锚点左右16格；失去视线后只搜索最后已知位置。适用地面兵种复用已有原生寻路，无有效路径时保留原生行为。普通爆炸手雷临近引爆时会触发安全通路检查；没有安全通路时保留原生反应。

UMM 面板提供目标记忆、追击和手雷避险三个独立开关。玩家控制、剧情、编辑器、未支持单位及已经提交的攻击阶段继续按各自原生职责执行。

## 安装与联机

直接下载 [EnemyAIEnhancement.zip](Release/EnemyAIEnhancement.zip?raw=1)，其中已包含0.19.4的DLL、Info.json及安装说明，无需自行编译。

在r2modman的Broforce配置中安装UMM，再通过 Settings → Profile → Import local mod 导入ZIP，使用 Start modded 启动。手动安装时，先退出游戏，将ZIP内 `UMM/Mods/EnemyAIEnhancement` 整个目录复制到所用配置的 `UMM/Mods/` 下。无需替换游戏程序集或安装额外资源。

从旧名称 `EnemyAIMultiplayer` 更新时，先退出游戏并移除旧 DLL，只启用一份 `Id=EnemyAIEnhancement` 的插件，保留已有 `Settings.xml`。

联机各端使用相同版本及一致设置。原生动作同步与增强决策属于不同职责；Workshop 世界中的部分特殊召唤、接触伤害和效果回放还需要对应的 [CustomMapMultiplayer](../CustomMapMultiplayer/README.md) 修复。当前组合验证使用 CMM 0.5.6 / 世界协议25。

## 构建与部署

复制 `LocalBroforcePath.props.example` 为 `LocalBroforcePath.props`，设置本机游戏 Managed 和 UMM Core 路径。需要 Windows .NET Framework 3.5 编译器及本机游戏程序集，不分发这些依赖。

```powershell
& .\BuildAndDeploy.ps1 -SkipDeploy
& .\BuildAndDeploy.ps1
```

第一条构建并更新安装包；第二条还会终止并确认本机游戏退出，再部署DLL和Info.json，保留设置。可选 `TestDeployModsPath` 指向另一台机器的Mods目录，部署前须先在该端退出游戏。`.csproj`可用于IDE或有相应工具链时的构建，不自动部署。

已有DLL时可单独运行 `& .\Package.ps1` 更新安装包，不重新构建或部署。打包只纳入manifest、说明、图标、DLL和Info.json，不包含游戏程序集、设置、测试或监督材料。

## 验证与限制

已完成实现阶段的定向检查、代表性自然战斗及双端验证。近期精简复用了未变化的行为证据，并对补丁目标、关键决策和实际联机结果进行差分核对。

Mega 榴弹阶段明确采用受控准备，不能视为完整自然阶段入口通过。部分方向、晚加入、混装、长会话和自然阶段仍未全面验证；本插件不承诺任意地图或所有技能组合均无差异。
