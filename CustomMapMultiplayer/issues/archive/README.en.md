# Archived Issue Records

> [Chinese](README.md)

This directory stores historical issues that completed their corresponding testing scope. Archived status means they are no longer current tasks; it does not mean that every proposal, extension, or old approach in the document was implemented.

For current features, limitations, and build procedures, use the project root [`README.en.md`](../../README.en.md), [`docs/DEVELOPMENT.md`](../../docs/DEVELOPMENT.md), and [`issues/README.en.md`](../README.en.md). Archived bodies are primarily for tracing the logs, root-cause analysis, and acceptance process from that time.
