# ISSUES-2026-09-05 联机聊天中文输入法支持

## 状态

**已修复，中文输入、候选提交、数字输入和再次打开聊天已通过真实键盘验证。**

## 根因

原生 `KeyboardInput.Update()` 只按 `KeyCode` 处理聊天输入，没有处理 Unity 的 `Input.inputString`、`Input.compositionString` 和 Windows IME 提交文本。因此中文候选、中文字符和部分符号无法完整进入原生 `MessageController.InsertLetter()`；发送后重新打开聊天时，数字输入还可能被输入来源判断过滤。

## 修复

- 聊天打开期间读取 IME 组合文本和提交文本，再交给原生 `InsertLetter()`。
- 允许 ASCII 数字通过提交文本路径进入聊天。
- 对同一帧由提交文本和按键同时产生的数字去重，避免重复插入。
- 保留原生 Enter、Esc、Backspace、Delete、左右移动和长按编辑行为。
- 只修改 `src/HarmonyDiagnostics.Chat.cs` 的聊天输入边界，不修改网络协议或 `Assembly-CSharp.dll`。

## 关键验证

- 中文输入和候选提交正常。
- 发送中文后重新打开聊天仍可输入数字。
- 数字不会因同帧输入来源重复插入。
- 长消息 viewport 由独立 issue 跟踪；本 issue 不改变消息长度上限和显示滚动算法。
