# 直接伤害转交与生命周期重复生成

2026-11-17。对应[世界同步复核摘要](../docs/world-sync-coverage/recheck.md)的 G1/G2。已实现公共路径修复，完成定向离线检查、标准 Release 构建和受控 Steam 双端验证；未提交或推送。原审计仍保留协议 17 的基线，本轮世界协议为 18。

## 原因与修改

G1：原有副本 mutation 门禁拦住了 `DamageOptional`、`BurnInternal`、`SetAlight_Local` 和弹体六参数 `Damage`，但这些入口没有全部经过原有命中请求。新增 `HarmonyDiagnostics.WorldMutations.cs`，按声明类型及完整参数签名识别这四类入口，复用目标 Owner 的可靠请求及结果通道。来源来自拥有端弹体、显式 actor、范围攻击上下文或当前本地英雄；无有效来源/NID 的调用保留原门禁。目标 Owner 执行原生虚方法，继续决定无敌、冷却、伤害类型及点燃资格。

请求 kinds 3–6 不预测死亡或击退。弹体 `damageDelay` 使用该 kind 的 x 槽传输，`newPlayerNum` 使用 direction 槽，原值交还目标 API；没有增添包字段。Map 的 Doodad、点燃及弹体范围入口维护可嵌套的来源上下文，燃烧 tick 也保留拥有端来源。接收期间只放行本端拥有的目标；嵌套影响另一 Owner 的对象时仍继续转交。

原有公共 `KnockAndDamageUnit`/`HeadShotUnit` 和 `Damage_Networked` 同时拦截远端英雄动画的再次模拟，避免已有拥有端请求与目标端动画各扣一次。拥有端弹体上下文和原生未注册 DamageRelay 回退继续保留。没有按方法名把所有 `Unit.Damage` 或原生 RPC 都改成新请求。

G2：生命周期回放仍会调用带生成副作用的原版代码。新增 `HarmonyDiagnostics.WorldReplayGeneration.cs`，启动时检查原版 BroforceObject 的 Death/QuietDeath/Gib/MakeEffects/DestroyBlockInternal/ActuallyCollapse。对其中直接调用的静态 `MapController.Spawn*` 和 `Networking.Instantiate*`，仅在返回值被 `pop` 丢弃、存入从不读取/取址的局部变量，或返回 void 时建立调用点边界；副本回放消费参数并跳过工厂，继续视觉及清理代码。后续会读取返回值的调用保留原契约，避免引入空引用。

作用域同时覆盖 `_worldApplying` 回放和原生副本确认：实测确认破箱确认可在 `_worldApplying=0` 时调用 `MakeEffects`，仅检查该字段会漏拦；实际 APC 二进制也会将第一个士兵返回值存入未读局部变量，只识别 `pop` 会漏掉一个士兵。最终实现和回归检查均覆盖这两个实际分支。钱币的 void 公共工厂 `CreateMoneySpray` 在此作用域内跳过；原生 `InstantiateRPC`、已有 Pickupable 的 `Launch` 和整个 Death 均不被全局禁用。现有机枪座 `mookKilled/GunnerEjected` 适配继续生效。

源码涉及新增的两个文件、WorldState/WorldProjectiles/WorldFire 及项目编译清单。没有修改 Aquabro 源码，没有增加常驻全场扫描。

## 边界及清理

该生成边界只处理上述原版程序集、生命周期方法和可证明返回值未使用的调用点，以及回放中的钱币公共工厂；不宣称已覆盖所有辅助函数链、会读取返回值的召唤、第三方程序集、触发器或全部 Instantiate。`DamageOptional` 的同步 bool/ref 显示反馈没有跨网络回传，命中反馈及穿透行为仍需专项覆盖。原生 RPC 和任意直接字段写入不属于本轮全部迁移的范围。

APC 原有摩托车释放分支、完整活动 AI 战斗、多加入方、异常网络、长期燃烧/长期联机及全部角色/Boss 未验收。审计 G3–G7 维持原结论。本轮已完成授权范围的修复和必要定向验证，无部署阻碍；这些边界不能由本轮样本推定通过。

临时观测脚本已卸载并从磁盘删除，测试夹具及残余对象随进程结束清除；两端 TestMod 自动清敌设置均恢复原值 true。最终 WMI 查询双方 Broforce 进程数均为 0。已分别读取两端最新 `.log` 与 `.trace.log`，包括文件长度元数据仍为 0 时的内容；没有新增截图或证据目录。用户原有交接、探针和证据材料保留。
