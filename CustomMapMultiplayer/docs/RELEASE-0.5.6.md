# 0.5.6版本说明

当前发行版本为 **0.5.6**，世界状态协议 **25**。联机各端应使用同一版本；新增同步消息不能据此推断与旧协议混装兼容。

## 同步修复

保留0.5.2—0.5.4引入的特殊敌人与榴弹效果修复：Warlock传送门配置及召唤/抛出链、Lost Soul接触伤害来源、Screecher/Baneling最终效果，以及继承MakeEffects的榴弹效果方法身份。游戏表现、实现边界和对应验证见 [问题记录](../issues/ISSUES-2026-11-22-特殊敌人与榴弹效果同步.md)。

此前直接伤害/碎尸、地雷路由与倒计时、物件受损状态、持续状态及载体加入恢复等既有修复保留。G1–G7旧检查数仍归属各自历史构建，未在此版本全部重跑，详见 [世界同步复核](world-sync-coverage/recheck.md)。

## 体积与执行成本

0.5.5将固定房间/层查询改为等价原生成员访问；0.5.6进一步缓存玩家槽位字段元数据，并直接读取RoomInfo固定字段，保留Trim、null、fallback及当前可变数组引用。

DLL从精简前0.5.4的521728字节减至521216字节，累计减少512字节。0.5.5→0.5.6本身减少0字节，收益为局部反射调用减少。新增同步修复改变过更早发行版的体积，不能把精简基线收益写成相对所有历史版本都更小。没有测定整体FPS提升幅度。

## 验证与发行产物

最后一批比较了1325个未改动方法的解析IL、局部变量和异常区间，另在双端菜单及同一在线房间核对真实玩家数组、冷热读取、可逆槽位变化、null和候选异常分支、字符串Trim、整数边界，以及实际RoomInfo和完整关卡结果快照。固定字段读法保留基类字段语义。

特殊敌人证据沿用各修复构建，坦克及受控Mega榴弹代表在后续精简构建完成回归。Mega自然阶段入口、全部攻击方向、晚加入、多加入方及长会话并未全部验证；酸作用0样本不代表额外伤害。对应EAI组合验证见 [EnemyAIEnhancement验证说明](../../EnemyAIEnhancement/docs/VALIDATION.md)。

发行目录DLL、Info.json、manifest以及ZIP内对应文件已核对一致，版本为0.5.6。双端验证后已恢复设置、卸载临时脚本、清理测试对象并关闭游戏。此次Git发布整理未改生产代码或DLL，不重复构建或开房。
