## 当前版本的验证结果

2026-11-21 的三轮精简累计将 DLL 从 **100,864 降至 94,208 字节**，减少 **6,656 字节（6.60%）**。动画表和蒙版无损打包、重复逻辑与转发入口清理、水花和酸源集合延迟分配均已完成；本轮覆盖范围内的原有功能保持一致。

| 验证类别 | 已确认范围 |
| --- | --- |
| 构建与回归 | 相同正式参数独立编译；蓄力、水爆、四技能综合、贴图初始化、暂停单步五组回归通过；相关编解码检查通过 |
| 数据与资源 | 五类完整蒙版逐字节一致；506 项帧表、10,019 个动画样本及 31 份 PNG／JSON 与精简前一致 |
| 实机前后对照 | 四技能双向、30／60 FPS 完整周期，以及染色、冷却、HUD、地形与接触查询结果一致；酸源集合延迟分配及状态复用符合预期 |
| 真实双端联机 | 本机房主、5700G 加入方；双方普通／蓄力投掷、四技能、七柱共享伤害、鲨鱼左右操控与起跳、伤害及吸附权限、弹药和 HUD 定向检查通过 |
| 验证后清理 | 有效周期结束时双方活动特效与屏障均为零；测试脚本、补丁与临时平面清理后关闭两端游戏 |

双端测试使用 `The brocountry / Test Evan2`，部分项目使用临时平面和提高血量的原生网络目标。具体用例、失效样本排除、指纹和部署依据见[第三轮验证报告](docs/精简批量补充验证-2026-11-21.md)。第一、二轮的独立结果分别见[第一轮报告](docs/精简验证-2026-11-21.md)和[第二轮报告](docs/精简补充验证-2026-11-21.md)。

## 仍需确认的事项

| 事项 | 当前结论与剩余范围 |
| --- | --- |
| 三叉戟飞行连续性 | 60 Hz 状态通道已整合到 CMM；当前版本的生成、弹速、水花和拥有端逻辑定向检查通过。两端互换攻击方后的连续性体验尚无最终验收结论，见[问题记录](issues/2026-11-15-三叉戟飞行联机断续.md) |
| 三叉戟显示遮挡 | 显示深度修复、暂停现场对照和定向回归已有通过记录；用户正常战斗体验仍待确认，见[问题记录](issues/2026-11-11-三叉戟飞行被场景物件遮挡.md) |
| 血水配色完整体验 | 渐变时序、颜色及精简前后确定性结果已验证；正常战斗和双端联机中的完整染血流程尚无专项体验验收，见[配色记录](issues/2026-11-11-技能血水配色渐变.md) |
| 历史诊断未闭环 | `HeroController.AddPlayer` 嵌套异常根因、严格零 HP 变化的撞墙验收仍缺少闭环记录；不将其写为当前必现故障，见[Trident 记录](issues/2026-10-29-Trident生产代码回归修复.md) |
