# 2026-10-20 四技能锯齿受伤入口修复

运行时测试 测试战役关卡，玩家约 (已脱敏坐标)；四个 SawBladeEdge 为 SawBlade，固定状态、血量 5、可见、未设玩家免疫，球碰撞体启用且在 Ground（8）层，但均不在 Map.destroyableDoodads 中。原生 SawBlade.DamageOptional 始终返回 false，不能通过普通物件伤害接口处理。涌泉／漩涡此前漏掉此类对象，狂潮／猎杀虽可能经地形碰撞提交伤害，但未统一处理。

四技能共享接触入口现在显式识别 SawBlade，使用其原生 Damage（含网络伤害入口），沿用可见像素、遮挡、拥有端及技能预算。狂潮对锯齿使用共享周期预算，最多 26 点基础伤害，不将锯齿判为墙；猎杀单次，漩涡／涌泉沿用原周期。隐藏或玩家免疫的锯齿不受伤；脱落状态的原生 invulnerabilityTime 未结束时不提交伤害，也不提前占用技能预算。

原生规则仍有效：固定锯齿血量降到小于 0 时先 Detach，脱落后血量重置为 3；脱落无敌时间结束后，血量再次降到小于 0 才 Death。不是一击强制删除，也不保证一次技能跨过整个无敌阶段。BossBlockSawBlade 发射器继续走 BossBlockWeapon 入口，DroneSawBlade 继续走 Unit 路径。
