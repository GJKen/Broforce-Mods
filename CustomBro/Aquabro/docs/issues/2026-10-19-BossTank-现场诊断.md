# 2026-10-19 BossTank 现场诊断

MCP 连接到 `测试场景` 场景、测试战役关卡，玩家为 Aquabro。检查期间保持 `Time.timeScale=0`。加载中的 DLL 与两个游戏目录中的 DLL 版本标识均已脱敏，与本轮精简构建不同，因此下面复现的缺口已存在于精简前版本。

当前飞行坦克 `BossTank` 和受伤部件 `BossPiece` 都继承 `NetworkedUnit`，并非 `Unit`；现场没有 `DamageRelay`。右履带碰撞部件剩余 8 点血，座舱为 140 点血且 `immortal=true`，左右炮组已被摧毁。座舱免伤需遵循原版阶段转换，不能通过直接清除 `immortal` 绕过。

本地诊断脚本 `tests/Probe-BossPieceDamage.cs` 在右履带可见像素接触位置调用当前 DLL 的生产方法，临时拦截 `BossPiece.Damage`，只记录请求、不执行扣血，以免推进阶段或击杀 Boss：

| 调用路径 | 捕获到的部件伤害请求 |
| --- | --- |
| 普通／蓄力的 `ApplyWaterImpactUnits` 单位分支 | 无；该分支仅处理 `Unit` |
| 普通戟完整 `WaterHitGround` 碰撞路径 | 5 点 `Crush`，通过 `DamageGround` 间接命中部件 |
| 蓄力戟完整 `WaterHitGround` 碰撞路径 | 14 点 `Explosion`，通过水爆 `DamageGround` 命中部件 |
| 怒海狂潮 | 24 点 `Crush`，来自场景物件分支；不是普通单位分支的 26 点伤害 |
| 深海猎杀跃出 | 28 点 `Crush`，来自场景物件分支 |
| 深海漩涡吸附伤害脉冲 | 无，部件未进入 `DamageRelay → Unit` 流程 |
| 深海涌泉 | 无，部件未进入 `DamageRelay → Unit` 流程 |

这证实漩涡／涌泉存在 `BossPiece` 支持缺口；不能把普攻概括为完全无法伤害坦克，也不能把拦截到请求当作实时战斗扣血验收。普攻和水爆仍缺少统一的部件直接命中／范围接触路径，当前依赖场景伤害接口。

这次诊断只完成定位与记录。当时提出的独立部件路径、关联组去重、漩涡／涌泉预算和普攻碰撞覆盖，已在后续[Boss 兼容修复](README.md#2026-10-19-boss-部件兼容修复)中落实；上表保留为旧 DLL 的诊断证据，不代表新版行为。

探针结束后已卸载，临时补丁与生成的测试弹体／水花均已清理；右履带仍为 8 点血，游戏继续保持原暂停状态。
