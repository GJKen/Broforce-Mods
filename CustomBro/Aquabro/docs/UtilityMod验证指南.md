# 用 Utility Mod 检查不同敌人的技能效果

更新日期：2026-10-22。这份说明用来检查“同一个技能，换一种敌人还是否正常”。毒水腐蚀的既有结果见 [酸液敌人核对](酸液敌人核对.md)。

## 漩涡查漏与修复结果

修复前通过 MCP 调用了 Utility Mod 右键 **Spawn Enemy** 使用的同一个生成入口，核对八组菜单的全部 66 项。每项分别放在人物左、右前方约 120px，脚下铺平地，等待敌人完成生成准备，再调用实际释放方法。修复后专门复查六项可受伤虫类，左右共 12 条通过；其它 57 项保留修复前结果，未重复全菜单验收。

| 菜单里的敌人 | 本次看到的表现 | 当前结论 |
| --- | --- | --- |
| Sand Worm（沙虫） | 漩涡仍出现在前方默认位置，没有去虫所在的位置 | 原版本体不能像普通 Boss 一样被打掉血，单独列为特殊敌人，不计入下面四项可受伤虫类的遗漏 |
| Boneworm（骨虫） | 旧版漏选；新版在露出部位下方生成 | 已修复，左右实际释放通过 |
| Boneworm Behind（后景骨虫） | 旧版漏选；新版在露出部位下方生成 | 已修复，左右实际释放通过 |
| Alien Worm（异形虫） | 旧版漏选；新版在露出部位下方生成 | 已修复，左右实际释放通过 |
| Large Alien Worm（大型异形虫） | 旧版漏选；新版在露出部位下方生成 | 已修复，左右实际释放通过 |
| Alien Facehugger Worm、Alien Facehugger Worm Behind（两种抱脸虫发射虫） | 左右两边均能把漩涡放到它下方 | 新版复查通过，身体位置离开头部时也继续识别露出的部位 |
| Drill Carrier（钻地运兵车） | 生成后先进入地面下方，本次没有被选中；临时抬到地表后左右均能选中 | 地下与出土状态要分开测；本次没有完成自然出土后的战斗验收 |
| Villager（村民） | 不会被漩涡自动选中 | 本次生成的是友方且无敌，按现有规则排除 |
| 其余 57 项 | 修复前左右两边均能把漩涡放到生成的敌人下方 | 保留此前通过记录，本轮未重复全菜单验收 |

其余 57 项包含普通兵、三种自爆兵、重装兵、两种机甲、两种喷气兵、异形、地狱敌人、菜单 Boss、其它坦克／卡车／摩托／炮台／飞艇，以及猪、腐烂猪、遥控车。它们本次均被当作可选目标；猪也会影响落点，不能仅凭菜单分组名称判断敌我。

大型机器人的炮臂也可能成为较近的目标。本次漩涡出现在靠近人物一侧的炮臂下方，不一定正对机体中心。

旧版漏选是因为这些虫不在普通敌人名单中。新版改为寻找可受伤虫类实际露出的部位，不再依赖那份名单；主体仍藏在地下、头部露在前面时，也能找头部下方的地面。部位关闭或被护甲保护、死亡、隔墙、超出距离或下方无地面时仍不选中，不会因此把 Boss 吸到空中。沙虫本体没有普通扣血处理，继续单独记录。

本次游戏保持暂停，让敌人完成生成准备，但没有让战斗继续、没有结算伤害。因此“落点通过”只说明漩涡能出现在它下方，不代表已验收吸力、扣血、腐蚀、Boss 登场／露头阶段或远程联机。特别是虫类还应在正常露头、缩回和移动时再测。

## 哪些敌人会被卷动

漩涡的“选落点”“伤害”和“吸力”分别判断。下面按实际敌人类别整理；不是逐种实战通过名单。

| 敌人 | 吸力表现 |
| --- | --- |
| 普通步兵、盾牌兵、喷气兵、火箭兵、忍者、自爆兵等 | 接触漩涡会被拉扯；若死后留下完整尸体，也能继续卷动。自爆或被打碎后没有完整尸体可吸 |
| 普通／强化／精英重装兵 | 活着和留下的尸体都能卷起；尸体不会因此复活或恢复行动 |
| 狗、抱脸虫、异形、飞蚊，以及地狱犬、亡灵兵、术士、处刑者、飞骷髅等 | 同样接受吸力；只有仍留在场上的完整身体参与，不能凭类别保证死后一定留下尸体 |
| 装甲兵（Mech／BrownMech）、特殊 Boss（Satan／SatanMiniboss／CR666） | 会提交吸力，但保留原版抗推和阶段限制，不能保证像普通兵一样悬空 |
| 坦克、大型机甲（Terrorbot）、直升机、卡车、炮台、摩托、钻地车和各类巨虫 | 不持续吸起；符合条件时仍可作为落点或受到伤害 |
| 猪、村民、遥控炸弹车，以及箱桶、牢笼、Boss 独立部位 | 不参与持续吸力，受伤规则另算 |

所有可卷动目标仍须在水体范围内、无遮挡且允许受伤；友方、无敌和已经中酸融化的目标不会被拉扯。自动找落点依然只找活敌，不会专门追着尸体释放。

尸体修复后，普通兵与普通重装兵完成左右共 4 项实机定向检查：通过原版伤害杀死后，正常游戏物理下调用实际吸力，尸体均离地并保持死亡状态。此项暂不包含完整技能伤害周期、逐种敌人战斗或联机；证据见本地验证归档。

## 在游戏里怎么查

1. 进入便于重开的测试关，用海王切到深海漩涡。先找一段开阔平地，清掉附近会干扰落点的其它敌人。
2. 打开 Utility Mod 的右键菜单，选择 **Spawn Enemy**。按菜单各组逐项生成，每次先放一只，放在人物面前约 6～8 格、与人物差不多高的位置。
3. 等敌人真正出现并站稳。喷气兵、钻地车和虫类要确认它没有飞走、藏入地下、缩回或消失；刚点完菜单就放技能，可能测到“还没准备好”。
4. 看漩涡是否出现在这只敌人下方，再换到另一侧重测。别只看它有没有被吸起来：坦克能作为落点，也可以受伤，但不会像小兵一样被卷到空中。
5. 再放一只更近的敌人，看漩涡会不会优先去近处；把近处敌人杀掉后，用新的一次施法检查是否改选活敌。已有漩涡生成后不会追着新目标跑。
6. 将同种敌人分别放到墙后、一格高台阶上、坑里和离地较高的位置。实墙后应选不到；矮台阶不能一概当成墙；高差太大或下方没有合适地面时，允许退回默认落点。
7. 删除上一轮敌人和技能，再换下一种。遇到异常，记下菜单原名、左右方向、地形、敌人是否已露头，以及“漩涡出现在哪儿”，尽量留截图或录像。

漩涡现在的找目标范围约为向前 11 格、上下 6 格；找目标时还需要在目标下方约 5 格内找到地面。没有合适目标时，通常向前约 4 格释放；近处有墙会更靠近人物。测试飞行敌人时，先让它靠近地面，再测高空状态。

检查次数消耗时关闭 Utility Mod 的“无限技能”；它会在次数用完后补满，容易误以为海王没有消耗。只检查命中时可以开着，但应记录这一设置。

## 换其它技能时看什么

| 要查的效果 | 游戏里怎么对照 |
| --- | --- |
| 狂潮 | 小兵能否被打到；坦克、卡车和大型敌人能否挡住浪；敌人死亡后浪是否在剩余时间内继续前进；墙后敌人是否安全 |
| 猎杀 | 先游到目标附近再跃出，看鲨鱼身体接触时能否打中；水花碰到而身体没碰到时不要当作必定命中；再测高台、深坑和入水后的目标 |
| 漩涡 | 分别记录出现位置、能否卷动、持续扣血和收尾打击；坦克没有被卷起不等于技能无效 |
| 涌泉 | 看敌人是否被不同水柱打中、同次七柱是否共同限制攻击次数；再测台阶、牢笼和墙后目标 |
| 毒水 | 先生成新敌人测清水，再生成另一只测毒水；观察变绿、惊慌和融化。每轮换新敌人，避免把已有酸液效果当成这次技能的效果 |
| Boss 与装甲 | 在正常战斗中分别测护甲完整、弱点打开和不同部位；同种普通武器能不能打伤也作对照。没有扣血时先确认是否正处于无敌阶段 |
| 拦弹 | 让敌人实际开火，看弹丸接触水体后是否消失，再测水体消散后的情况；近战和已经发生的爆炸不属于拦弹 |

遇到“生成后马上消失”“还没露头”“原版攻击也打不伤”的情况，应单独记录原因。不要直接写成技能漏伤，也不要为了得到通过结果，先改敌人的血量、敌我或无敌状态。

可以按这一行记录，方便回头对照代码和文档：

```text
菜单敌人｜技能／清水或毒水｜左／右｜平地／台阶／墙后／地下｜出现位置｜是否卷动｜血量前后｜是否变绿／融化｜结论／截图
```

## MCP 辅助核对与本次证据

本地脚本 [Verify-UtilityMaelstromPlacement.cs](../tests/Verify-UtilityMaelstromPlacement.cs) 使用同一个 `Utility_Mod.Main.SpawnUnit` 入口生成敌人。需先暂停并使用 Aquabro；执行后等待状态 `DONE 132`，表示 66 项、双朝向结束。`issuesOnly=true` 只复查七项虫、钻地车与村民，结束为 `DONE 18`；`wormFixOnly=true` 验证六项可受伤虫类，结束为 `DONE 12`，并额外检查主体位置离开头部、部位关闭和墙体阻挡。

脚本等待四个 Unity 帧，让原版 `Start` 完成；仅禁止临时敌人的屏外禁用，不修改其血量、无敌或敌我。它调用当前 DLL 的找目标和实际释放方法，核对两者位置是否一致，然后删除临时敌人、漩涡和地面，恢复人物位置、面向、次数及施法字段。少量原因对照会临时把虫加入名单或把钻地车抬到地表，记录在独立字段中，不能将这些结果算作正式代码通过。

修复前后运行版本标识均已脱敏。完整 132 条旧结果、18 条原因对照及 `修复后虫类落点.txt` 的 12 条新结果保存在本地验证归档（未随发布文档提供）；现场脚本和临时证据可能不随发布包提供。结束应卸载脚本并清理临时对象，再关闭游戏。正式代码或资源有改动时，仍须先确认游戏退出，再构建部署。
