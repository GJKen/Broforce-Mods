# Utility Mod 生成菜单与毒水腐蚀

右键生成敌人的具体操作，以及如何分别检查漩涡落点、吸力、扣血和其它技能，见 [Utility Mod 验证指南](UtilityMod验证指南.md)。本页只记录腐蚀对照；能否腐蚀与能否被漩涡自动选中分别判断。

2026-10-21，通过 MCP 读取正在运行的 Utility Mod／RocketLib 八个菜单分组，共 66 项。使用相同 `Utility_Mod.Main.SpawnUnit` 生成入口，在隔离坐标对照原版 `DamageType.Acid`（方向 0）和二阶段狂潮、漩涡脉冲、涌泉的生产接触方法。

下表中的“通过”表示原生覆酸标记为真，三种技能与原版酸液伤害对照一致。修复前有 31 项进入原版覆酸，除盾牌兵的涌泉路径外均一致；新版 29 项完成同样的对照且全部一致，两种喷气兵副本在命中前被原版清除，只保留旧版初始化后的通过证据。这是定向接触验证，不代表逐项完成自然战斗、融化全流程或远程联机验收。所有测试对象保留预设血量和酸液资格；为等待喷气兵初始化，临时禁止测试对象屏外禁用。没有改原版敌人预设或 Utility Mod。

## 原版条件与验证限制

| 菜单项目 | 依据与处理 |
| --- | --- |
| Mech、Brown Mech、Boomer、Satan Miniboss | 实际预设 `canBeCoveredInAcid=false`，毒水保留普通水伤害，不强制融化 |
| Snake、Facehugger、Xenomorph、Brute、Screecher、Baneling、Xenomorph Brainbox | 原版 Acid **伤害入口**不对这些类型执行普通士兵覆酸分支；毒水保留普通水伤害。Baneling／Screecher 的原生 Acid 伤害还有特殊死亡逻辑，不能把此栏写成“完全免疫所有酸液”。原版地面酸池直接调用 CoverInAcid，入口不同，本轮没有逐项酸池落地实测 |
| Stealth Tank、Terrorkopter、Terrorbot、Megacockter | 不是覆酸角色类型，保留 Boss 原生伤害规则 |
| Sand Worm、Boneworm、Boneworm Behind、Alien Worm、Alien Facehugger Worm、Alien Facehugger Worm Behind、Large Alien Worm | 七项虫类 Boss 预设不是覆酸角色类型，保留原生伤害规则 |
| Mook Launcher Tank、Cannon Tank、Rocket Tank、Artillery Truck、Blimp、Drill Carrier、Mook Truck、Turret、Motorbike、Motorbike Nuclear、Dump Truck | 十一项载具预设不是覆酸角色类型，保留普通技能伤害与原生护甲／弱点规则 |
| CR666 | 预设允许覆酸，但原生 Damage 要求在屏幕内。隔离坐标的原版对照和三技能均没有进入覆酸；本轮未覆盖屏幕内战斗，不能记为免疫或已通过 |
| Villager | 现场预设实例无敌，原版酸液与三技能均不覆酸；未解除无敌强测，不能推断普通状态免疫 |

本轮确认的生产代码遗漏是盾牌兵的方向阻挡，已修复。自爆兵三种变体没有复现类型排除或生产接触漏伤；此前现场“不腐蚀”的具体触发过程仍未还原，不能把它解释成自爆兵天生免疫，也不能声称已经定位该现场问题。

证据与可复用脚本位于 本地验证归档（未随发布文档提供）。新版 DLL 校验哈希已脱敏，实机加载新版本（标识已脱敏）。测试对象与脚本已清理，游戏最终关闭。
