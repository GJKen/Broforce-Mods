# 历史部署快照：涌泉共享污染

> 本页保存早期部署记录，原文件名仅用于保留旧链接。最新 DLL、部署和验收状态见[当前状态](../../当前角色实际应用状态.md)；当前机制见[机制说明](../机制实现细节.md)。

当时涌泉已改为同次整组共享污染等级、来源去重及颜色进度；该轮通过离线回归，未重启实机验证，详见[整组污染记录](../../issues/2026-10-20-涌泉整组共享污染.md)。此前已修复狂潮／猎杀普通场景物件伤害、水体拦弹及酸池污染的实体墙遮挡、漩涡收尾显示帧判定，并新增漩涡拆墙后扩大剩余路线；这些此前改动已通过游戏启动入口重启后的 MCP 游戏内对照。相关 DLL 哈希均为历史快照。
