# 海王三叉戟反馈记录

本文记录当前源码实际使用的原版接口、游戏实测结果及动画编辑反馈。动画素材检查与游戏内验证分别注明，避免后续修改时遗漏原版表现或混淆接入状态。

最新素材：2026-09-15 贴墙、悬挂、攀爬按 Rambro 对应动作逐像素修正，三份独立稿、[总稿](haiwang_trident_traversal-v2.aseprite)、身体图集与本地 PNG 已同步。本轮未重新构建或部署，详见本文末尾记录；此前五类地形动作的接入与部署记录继续保留。

- 普通投掷和蓄力投掷使用 `Map.HitProjectiles`，普通/蓄力命中半径分别为 6 和 8。
- 投掷地形命中使用 `ProjectileApplyDamageToBlock` 与 `CreateBulletPoofEffect`；弹体结束时使用蓝色水光消散。
- 近战单位命中使用带明确伤害参数的 `Map.HitUnits`：近战伤害为 8、尸体伤害为 0、`hitDead = false`，并补充 `CreateMeleeStrikeEffect` 与 `soundHolder.meleeHitSound`。
- 可投掷的存活 `Mook` 单独使用 `ThrowBackMook`，不叠加普通近战命中特效；尸体不参与投掷。
- 近战地形伤害使用 `MapController.Damage_Networked`，特效使用 `CreateBulletPoofEffect`，不使用敌人白色斩击特效。
- 水墙使用 `FlameWallExplosion` 的单位伤害、击退和近距离存活 Mook 抛掷路径；独立受伤部件通过 `RisingWaveDamage` 补充命中，并交给原版 `DamageRelay` 处理。
- 海王不提供额外空中起跳。三叉戟近战在起手、移动和退出时清理 `jumpTime`，保留已有纵向速度，避免收招后恢复过期的按住跳跃续升；地面起跳和蹬墙仍由基础角色逻辑处理。

以上接口和效果以当前源码为准；构建、部署和输入时序测试不能替代实际游戏内验证。

## 2026-09-14：近战收招后的二段跳

本机离线 `Test Evan2` 场景通过 Unity Inspector 只读接口观测，由用户手动复现。没有模拟输入、执行游戏运行时代码或注入热修复。

- 复现条件：起跳前后使用近战，持续按住跳跃；重复近战可多次推迟续升窗口的消耗。
- 异常样本：09:19:18.559，玩家 0 离地 31.428 单位，`yI=-0.992`、`doingMelee=true`、`jumpTime=0.123`；09:19:18.595，近战结束，`yI` 恢复到 `256.044`。期间 `lastJumpTime=385.8801` 不变，未碰墙。同一轮第二次近战结束后也出现了续升。
- 原因：`TestVanDammeAnim.RunMovement()` 的近战分支绕过 `jumpTime` 的递减。收招后，`CalculateMovement()` 看到跳跃键仍按住且 `jumpTime>0`，直接把 `yI` 重设为 `jumpForce`，不经过 `AirJump()`。原版 `BroBase.StartKnifeMelee()` 会清零 `jumpTime`，自定义突刺遗漏了这一步。
- 修复：在近战起手清理续升计时；近战移动期间处理新地面起跳重新写入的计时；结束或打断时再次清理。取消原先强制把正 `yI` 归零的处理。
- 验证：输入状态测试仍用于攻击时序回归；二段跳必须在加载新 DLL 后，手动重复上述组合，并确认空中收招时没有纵向速度重置。普通跳跃和蹬墙作为对照。
- 构建结果：`tests/Test-Trident.ps1` 通过 7 组场景、390 次断言；`BuildBro.ps1` 编译和部署成功，本地与部署 DLL 的 SHA-256 均为 `15c6a8925d3d6b6fb150f97c897dbcddbcd70c9469ecf638437c8e4a523e24f0`。用户已在重启后的游戏中确认多段跳修复。

## 2026-09-14：水墙无法命中骨虫 Boss

本机离线 `Test Evan2` 场景的 MCP 检查识别到两只 `HellBoneWormMiniboss`。读取时前方骨虫为 `125/125` 血，后方骨虫为 `50/150` 血，均已激活且未处于无敌状态。头部和身体使用独立的 `DamageRelay` / `DamageRelayThroatFlame`。

- 原因：水墙仅使用 `Map.HitUnits` 检查普通单位列表和主体坐标，缺少对独立受伤部件的碰撞检测。骨虫的头部与身体由 `DamageRelay` 转发伤害，普通单位路径不能覆盖这些部件。
- 修复：启用每个水墙节点的自定义回调，在相同的 12 单位命中半径内补查伤害转发部件，经过 `MapController.Damage_Networked` 和原版 `DamageRelay.Damage` 结算，保留护甲、免疫、伤害类型转换与受伤反馈。
- 去重与范围：普通单位路径已覆盖的目标不再补伤害；同一转发部件的多个碰撞体只处理一次。友方、死亡、无敌和不向单位转发伤害的部件不参与补充命中。
- 回调中的近距离 Mook 抛掷只选择存活目标，避免普通单位伤害结算后又把尸体当作存活敌人抛掷。
- 测试：原有攻击测试 7 组、390 次断言通过；新增部件伤害测试 6 组、16 次断言通过。新增测试编译实际 `RisingWaveDamage.cs`，以替身覆盖 Unity 查询与原版伤害接口边界，不能替代游戏内验收。
- 实测范围：已在游戏中确认修复版水墙技能可以对骨虫造成伤害。MCP 中途断连后已恢复，并重新取得旧版本的场景基线；本次确认以用户实际施放技能后的结果为准。没有模拟输入或注入运行时补丁。
- 构建与部署：`BuildBro.ps1` 编译和部署成功，本地与部署 DLL 的 SHA-256 均为 `8c3982feecef4ebbb5f0d05013d1f0190af4d57b986075bc9ad2210bda58a247`。原部署 DLL 已保留为 `.before-wave-relays-20260914-100157.bak`；当前游戏进程仍加载旧版本，需要重启后再验证骨虫受伤。
