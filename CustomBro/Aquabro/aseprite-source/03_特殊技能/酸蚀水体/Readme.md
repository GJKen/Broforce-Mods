# 酸蚀水体

狂潮、漩涡、涌泉各有 `skill-<技能>-acid-1.aseprite` 和 `skill-<技能>-acid-2.aseprite`，共六份正式分层源稿。帧数、尺寸、帧段、透明度与原特效稿一致。`配色预览.png` 从上到下为清水、一阶段、二阶段，从左到右为狂潮、漩涡、涌泉。

| 色阶 | 一阶段 | 二阶段 |
| --- | --- | --- |
| 最深 | #397B68 | #286E03 |
| 暗部 | #4D9B77 | #349303 |
| 中暗 | #58AE7C | #3BB000 |
| 主色 | #83D69B | #48C400 |
| 亮部 | #A9E8BA | #5EDC00 |
| 高光 | #D8F7D9 | #7EFF00 |
| 最亮 | #F1FFE9 | #CAFF8A |

二阶段参考 MCP 从原版沙虫 `Spit Ball Acid` 读取的颜色频次：#3BB000（662）、#48C400（384）、#5EDC00（130）、#7EFF00（26）、#349303（9）；增加深色描边和浅绿色最高光来保持水体层次。

猎杀不参与污染，不保留酸蚀源稿。三个水技能只改变 RGB，保持 alpha。运行时每阶段约 0.3 秒逐帧插值混色；同时吸收多份毒液时从当前颜色继续推进，经过浅绿再到毒液绿。只混合当前 128×128 动画帧，使用每个水体独立的材质／纹理，结束时释放，不修改共享素材。概率仍为一阶段 50%、二阶段 100%，具体分账及生命周期见角色 README。

日常直接编辑本目录源稿，运行 `BuildAssets.ps1` 导出；`tools/export_acid_skills.lua` 会验证透明度。`tools/generate_acid_sources.lua` 是初始配色重建工具，会覆盖本目录六份源稿，仅在明确需要重建时手动执行，不由常规构建调用。

渐变像素必须直接解码正式 PNG，不能从 `ResourcesController` 的共享渲染纹理调用 `GetPixels32()` 取源色。当前游戏版本实测共享纹理能正常显示，但 CPU 读回均为 0xCD，导致透明部分变成灰色矩形。解码用临时纹理，取得像素后立即释放，仍只为当前帧生成独立混色纹理。

污染与腐蚀仅限狂潮、漩涡、涌泉，来源按对象身份去重，连通酸池的多个对象可能连续升阶。渐变、腐蚀伤害分账与清理条件以角色 README 正文为准；本目录仅维护配色和导出约束。六张运行时 PNG 不能缺失，当前解码失败不会自动回退清水。
