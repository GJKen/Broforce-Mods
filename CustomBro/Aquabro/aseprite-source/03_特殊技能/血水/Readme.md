# 血水配色

四份 `skill-<技能>-blood.aseprite` 是可编辑的分层 Aseprite 源稿，保持原稿尺寸、帧数、透明度、图层与轮廓。猎杀只调整第 3、7、8 层水花，五层鲨鱼本体保持原像素。

配色取自 2026-11-11 实机 `WM_Hell` 的原生 `BloodPool` 贴图。通过 GPU 读回取得深色 `#730F1C`、主体 `#951223`、亮色 `#B70D23`，完整水体色阶为 `#730F1C、#851121、#951223、#B70D23、#C83B4A、#E46B76、#F59BA3`。

[preview.png](preview.png) 从上到下为狂潮、猎杀、漩涡、涌泉；从左到右为接触时、0.425 秒、0.85 秒的配色。预览读取保存后的正式源稿。

技能接触无遮挡的原生血池后立即开始一次渐变，用 0.85 秒变为血水颜色，离开血池后继续；重复接触不重置进度。同次涌泉共享进度，新施放重新开始。暂停冻结进度；技能按原寿命消失，较短的水柱可能在完成渐变前消散。血水只改 RGB，不增加腐蚀或改变伤害。原有酸液机制独立，酸液配色优先。

`BuildAssets.ps1` 通过 `export_skill_effects.lua` 的 `blood=true` 参数读取这些源稿，导出四张完整特效和猎杀前后两张水花。逐层逐帧检查 alpha 与鲨鱼身体像素，并沿用原有猎杀入水校准；不生成新判定蒙版或重复的鲨鱼本体图。

`tools/generate_blood_sources.lua` 是初次配色及预览重建工具，会覆盖本目录四份源稿；日常构建只导出，不覆盖编辑稿。
