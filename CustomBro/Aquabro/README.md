## 角色基础与操作

角色类为 `AquabroMod.Aquabro`，继承 BroMaker 的 `CustomHero`，预设基础为 `HeroType.Rambro`。当前插件版本 `0.1.0`，程序集版本 `0.1.0.0`，声明的 BroMaker 版本为 `2.6.2`，项目目标为 .NET Framework 3.5。

生命、基础跑速、跳跃、重力、普通受伤、复活、游戏模式的友敌关系，以及未专门覆盖的基础动作沿用原版预设和 BroMaker。代码没有另外定义一套生命值、跑速或跳高，不应把水体特效的尺寸当作角色碰撞体尺寸。启用蹬墙翻转与新版普通、蹲姿、击掌和投掷帧；攀墙、悬挂、攀边、滑索等仍使用原版运动逻辑和对应自定义外观。

按键使用游戏设置中的动作绑定，以下不写死键盘字母。

| 操作 | 当前行为 |
| --- | --- |
| 按住普通攻击 | 蓄力；达到 0.5 秒后为满蓄力 |
| 松开普通攻击 | 立即投出一次三叉戟；不足 0.5 秒为普通投掷 |
| 近战／小刀键 | 三叉戟前刺，使用原版小刀伤害接口 |
| 秀肌肉／Flex | 按顺序切换技能，并补满特殊次数 |
| 特殊攻击 | 释放当前技能；遥控鲨鱼期间再次按下则跃出 |
| 遥控鲨鱼时左右 | 移动鲨鱼并改变鲨鱼朝向 |
| 遥控鲨鱼时按下 | 取消梯子支撑，向下寻找实际地面；可以同时左右移动 |

初始技能为怒海狂潮，特殊次数为 3。配置中的 `fireRate=0.2` 不表示按住攻击自动每 0.2 秒发射；投掷由自定义的蓄力和松键逻辑处理。

## 普通攻击：三叉戟投掷

### 输入、出手与姿态

按住攻击累计蓄力，松开时只发射一支。满蓄力阈值为 **0.5 秒**；持续按住不会自动连续投掷。投掷后冷却 **0.2 秒**，冷却结束才允许开始下一次蓄力，冷却期间的按住时间不计入下一次蓄力；投掷收招动画长 **0.182 秒**。收招不会使投射物延后生成，投射物在松键出手时生成。

| 项目 | 普通投掷 | 满蓄力投掷 |
| --- | --- | --- |
| 蓄力时间 | 大于 0、低于 0.5 秒 | 至少 0.5 秒 |
| 水平初速度 | 400 | 664（400×1.66） |
| 出生位置 | 角色前方 14px；站立脚底以上 11px，蹲姿以上 8px | 相同 |
| 初始竖直速度 | 0 | 0 |
| 周围单位伤害 | 8，半径 12px | 按当前帧可见水花接触判定：接触点距爆心不超过 25.2px 时伤害 14，外围接触仅震飞 |
| 单次投掷 | 首次接触触发一次水花，然后销毁 | 相同 |

死亡、失能、登上直升机、搬投物体、被插住或吊起、抱脸寄生、酸覆盖、施放特殊技能或进入手势动作，会取消蓄力、收招和投掷冷却时序。近战也会清除这些状态，并独占身体与武器动作。贴墙、攀墙、攀边、蹬墙翻转等姿态不叠加普通分层蓄力手臂；实际发射仍受游戏基础输入和动作规则约束。

`trident.png` 是 64×32 的两帧图集；当前投射物外观初始化采样第一个 32×32 格，蓄力状态由计时和速度决定，不靠自动切到第二格识别。飞行实体使用 Predabro 已登记的普通／蓄力长矛网络 prefab，仅给 Aquabro 本次发出的实例替换三叉戟贴图和水花逻辑，不改共享 prefab 或 Predabro 本人。原版武器子渲染层被隐藏，Aquabro 的蓄力长矛不生成原版残影。历史 MCP 对实际 prefab 的检查得到 `fadeDamage=0`，当前没有随飞行距离主动降低伤害的自定义机制；生命期等未覆盖行为仍取原 prefab。

### 戟尖扫掠与贴身命中

视觉戟尖约在弹体坐标前方 24px。每次单位检测扫掠上一检测位置到当前戟尖之间的轨迹，选最先接触的有效活敌，避免高速飞行跳过敌人。

首次检测时，如果弹体仍在角色前方 0–40px 内，从角色身体横坐标开始扫到戟尖，补齐出生点前方 14px 造成的贴身盲区；首次观察到已飞远或在身后的弹体，则从弹体位置起扫，不把远处弹体的路径补回身体，也不向角色身后扩伤害。

敌人检测横向使用身体半宽 `width/2`；角色型目标的顶部使用当前 `headHeight`，其他单位顶部使用 `Y+height×2+3`，再在上下各留 3px 戟尖接触余量。命中点夹在目标脚底与实际顶部之间，兼容蹲姿和重装兵头部。排除自己、尸体、无敌单位及游戏规则不允许攻击的目标。

戟尖扫掠同时检查沿途实体墙，先碰到墙就撞墙起水花，墙后敌人不会被登记为直击；墙前的敌人仍可先命中。触发器、单位身体和 Boss 单位部件不当作普通墙体。普通／蓄力均适用，包含贴身补扫和高速飞行。原版出生检查若先在墙内触发命中特效，会将爆心移回迎面墙外 0.05px，避免从墙内绕过遮挡。

首次实体接触即在接触点触发水花。每支戟只结算一次水花并销毁，不连续穿透制造多次水爆。直击与周围范围伤害合并为同次水花的一次目标结算：直击伤害为 `max(长矛 damageInternal, 普通8／蓄力14)`，不因目标的脚底采样点离爆心较远而变成零伤害，也不会额外叠加一份独立直击伤害。

### 普通水花与蓄力水爆

| 项目 | 普通水花 | 蓄力水爆 |
| --- | --- | --- |
| 范围形状 | 以敌人 `(X,Y+6)` 采样点计算圆形距离 | 敌人身体矩形接触当前帧可见水花；透明部分不算，直击目标另有保底 |
| 伤害半径 | 12px | 可见接触点距爆心不超过 25.2px（72÷2×70%），造成 14 点伤害 |
| 外围冲击 | 无额外外圈 | 25.2px 之外仍碰到当前帧可见水花，仅震飞，伤害为 0 |
| 伤害类型 | `Melee` | `Explosion` |
| 检测时机 | 起爆立即一次 | 立即一次，之后在 600ms 内持续检测后来进入的活敌 |
| 防重复 | 同一水花每敌一次 | 同一水爆每敌一次，先进入外圈后进入内圈不补伤害 |
| 画面 | 48×48，12 帧，共 540ms | 64×64 源帧显示为 72×72，6 帧，共 600ms |

蓄力水花碰到敌人头部、身体边缘或脚部都能生效，不再只看脚底上方的一个点，也不再受旧 26px 单位初筛限制。身体边界采用当前 `width` 与 `headHeight`，非角色单位采用自身高度。判定与当前显示帧一致，只取非透明像素；按 72×72 显示大小换算，不把透明画布当水体。可见水花与身体的重合部分中，只要存在无遮挡且距爆心不超过 25.2px 的接触点，就按内圈结算；仅接触外围则只震飞。该 70% 以显示画幅半宽 36px 为基准，画面边角的可见水滴也可触发外圈冲击。

透明处、未接触和墙后的目标不会提前登记，后续进入仍有一次机会；已经在外圈被零伤震飞的目标已计入本次命中记录。蓄力检查爆心到实际水体／身体接触位置的实体墙遮挡；普通水花仍检查爆心到 `(X,Y+6)` 的遮挡。完整墙后的目标不受伤、不震飞，也不消耗本次命中机会。墙被摧毁后，仍在 600ms 有效时间内的蓄力水爆可以命中恢复无遮挡的目标。只伤害有效活体；不存在残留水洼、减速或动画结束后的持续伤害。

普通水花横向冲力为远离爆心方向的 110，向上 90，爆心重叠时用投掷方向决定左右。蓄力冲力按目标相对爆心方向分配：横向为 `dx/距离×400`，中心重叠时为投掷方向 100；竖向以 `dy/距离×400+260` 为基础，并至少为 `max(260, abs(横向冲力)+40)`。最终击退、翻滚、后空翻和抗击退由目标原版逻辑处理，不修改 `canTumble` 等属性。

普通动画前 4 帧各 35ms、后 8 帧各 50ms。蓄力只播放正式 22 帧源稿中的第 17–22 帧，源帧各 50ms，运行时各 100ms。水花层级为 Z=-12，和四项技能的 Z=1 分开。

### 地形、物件、弹丸与声音

命中时以弹体当时的水平速度判断普通／蓄力：`abs(xI)>500` 为蓄力，否则为普通，不仅依赖按键时长或贴图。

- 普通碰地：拥有端先调用 `DamageGround`，伤害取长矛 `damage`，类型 `Crush`、半径参数 16px，位置沿碰撞法线向外偏 3px，再触发水花。
- 普通物件：使用长矛 `damageInternal`、原长矛伤害类型与速度，`DamageDoodads` 的半径参数为 8px。
- 蓄力破土：起爆时调用一次 `DamageGround`，基础 14 点 `Explosion`，半径参数 18.2px。
- 蓄力物件：起爆时调用一次 `DamageDoodads`，基础 14 点 `Explosion`，半径参数为 18.2×0.6=10.92px，冲力参数为 0；物件接口内部规则仍由原版处理。
- 蓄力弹丸：只检查敌方可受伤投射物，其**中心**位于 18.2px 圆内时施加 14 点爆炸伤害；这可以触发弹丸自身的受伤／爆炸反应，与水技能直接熄灭弹丸不同。
- 蓄力摇树：矩形接口使用圆的内接正方形，横竖范围各约 18.38px（26×0.70710678），强度 60。

上列场景破坏、弹丸与震屏仍采用各自原有半径，不随本次单位接触范围扩大。上述地形、物件、弹丸和摇树只在起爆时结算，不会随 600ms 动画重复执行。单位检测则继续到动画结束。普通水花后续动画仅显示。

蓄力震屏只由拥有端触发，且角色 `(X,Y+6)` 距爆心必须小于 26px，强度为 `0.2×(1-距离/26)`，不产生远距离全屏震动。攻击使用 Predabro 的声音资源，投掷会惊动角色周围 120px 内的野生动物。

## 近战：三叉戟前刺

小刀键使用自定义三叉戟动作，地面、蹲姿、空中各有对应身体与武器帧。地面／蹲姿使用前 4 个源帧，空中使用后 4 帧；动作倍率 **1.4**。内部命中时间为 0.16 秒、总时长为 0.25 秒，实际约 **0.114 秒命中、0.179 秒结束**。一次动作只调用一次 `PerformKnifeMeleeAttack(true,true)`，伤害、范围和附带效果沿用原版小刀接口，不另设水爆。

开始条件：活着，未在遥控鲨鱼，未进行近战，未眩晕／冻结，未登直升机、被插住／吊起、抱脸／酸覆盖或搬投物体，且不在特殊技能动作中。开始时取消蓄力、投掷收招与冷却，清空续跳时间，空中／地面状态由原版 `StartMeleeCommon` 决定。

地面前刺允许半速左右移动；空中继续正常下落重力并遵守最大下落速度，不能靠此动作续跳。39×32 源稿的武器按阶段裁切并恢复偏移，保留前刺戟尖；结束或取消时恢复普通武器锚点与动画。

## 技能选择与施法通则

### 选择、次数与释放

秀肌肉依次切换：**怒海狂潮 → 深海猎杀 → 深海漩涡 → 深海涌泉 → 怒海狂潮**，每次切换由拥有端补满 3 次。技能选择按玩家槽位 0–3 独立保存，在同一运行期间重生继续使用该玩家上次选择；这不是跨游戏进程的存档功能。

切换接在原版按键上升沿调用的 `SetGestureAnimation(Flex)`，每次按下切换一次。`TriggerFlexEvent` 在原版流程中会触发两次，不能把切换移到该事件，否则一次输入会跳过一个技能。

切换需活着、未失能、未近战、不在普通／口袋特殊技能动作中，并且场上没有当前鲨鱼实例。鲨鱼跃出后虽然角色恢复控制，**仍需等鲨鱼动画结束才能切换或再次释放鲨鱼**。切换会取消当前蓄力与投掷收招，清理本角色场上技能特效，再执行原版秀肌肉手势；普通重复施放可存在多个技能实例，切换则会清掉它们。

特殊攻击起手拒绝死亡、失能、近战或正在施法的状态；猎杀另外要求可下潜的地面／梯子接触。次数不足时沿用原版 HUD 闪烁，不生成技能。技能没有另外设置统一固定冷却，但受各自动作、次数和猎杀实例限制。一次施法固定起手时选中的技能，在实际释放帧扣 1 次并触发原版特殊技能事件；涌泉七柱总计只扣 1 次，鲨鱼二次按键跃出不另扣。

### 施法时序与技能总览

施法身体画布 32×32，每帧 65ms；按键起手立即显示完整第一帧并隐藏独立武器手臂，避免旧手臂闪现。均在第 3 帧（代码索引 2，约 130ms 前摇）实际释放。

狂潮共 6 帧，至第 6 帧恢复；其余正式源稿各 8 帧，通常至第 8 帧恢复。猎杀在第 3 帧成功生成鲨鱼后立即退出人物施法，后续由遥控状态接管，源稿剩余帧不用于持续锁住角色。猎杀在释放帧再次检查支撑，前摇期间离地导致条件不满足时，不扣次数、不生成鲨鱼。

| 技能 | 单目标基础伤害 | 主要时长 | 破坏地形／物件 | 水体拦弹 |
| --- | --- | --- | --- | --- |
| 怒海狂潮 | 26，每实例一次 | 最多前进 1.5s，消散 0.5s | `Crush` 24，每对象一次 | 有，仅有效阶段 |
| 深海猎杀 | 跃出 28，每实例一次；潜行无伤 | 遥控取 Dredd 导弹寿命，之后跃出 1.1s | 跃出 `Crush` 28，每对象一次 | 无 |
| 深海漩涡 | 每 0.4s 为 3，最多 9 次；收尾 9，合计上限 36 | 运动／吸附 3.6s，消散 0.6s | 无 | 有，仅有效阶段 |
| 深海涌泉 | 每次 4，整次施放每敌最多 7 次，合计上限 28 | 每柱 1.4s，最外延迟 0.42s，全阵列最多 1.82s | 无 | 有，仅有效阶段 |

上限指完整有效接触且目标原版受伤规则允许时的基础值，不保证任何敌人实际都承受满额。击退值见各技能说明。

## 怒海狂潮（tidal-wave）

### 生成、运动与动画

在角色当前 **X、Y** 生成，方向取释放时朝向。原先前移 26px 的出生偏移已移除，水体从角色位置展开以覆盖贴身敌人。缩放 0.85，128px 源画幅显示为 108.8px；伤害区域取实际水体像素，不是整块画布。

沿释放方向以 **160px/s** 水平前进，最多 **1.5 秒／240px**，高度固定，不随地面升降。每次推进拆成最多 8px 的小步检测碰撞，避免一步跨墙。

代码帧 0–2 每帧 0.1 秒起浪，之后按 3→4→5→4、每帧 0.1 秒循环；1.5 秒后停下，代码帧 6–15 每帧 0.05 秒消散，总时长最多 2 秒。遇仍然存在的阻挡时提前停下并进入 0.5 秒消散。消散阶段不伤害、不破坏，也不拦弹。

### 伤害与阻挡

单位按身体矩形与当前水体像素接触，留 5px 余量；脚底水线 `Y+1` 及以下的部分裁掉。扩大初筛覆盖大型身体，不把敌人的身体或 Boss 部件当作阻止浪前进的墙。

每个有效目标每实例只承受一次 **26 点 `Explosion`**，横力为朝向 **420**、上力 **300**。接触仍要求无遮挡，不隔实体墙伤人。

地形和场景物件按同样水体边界处理，每个对象一次 **24 点 `Crush`**，横力 **420**、上力 **80**，物件免疫规则沿用原版。完全位于水线下的支撑底板受保护。受击后仍有效、顶部高于水线 8px 的实体障碍会阻停狂潮；可受伤且被判为不可穿透的 Doodad 也会阻停。被成功清掉的障碍可继续穿过，单位不阻停。

## 深海猎杀（shark-hunt）

### 释放条件与人物状态

允许在有支撑的待机、跑步或爬梯状态释放：支持普通地面、梯顶及实际接触的梯身。跳跃、掉落、墙滑、攀墙、攀边和滑索不允许起手。起手与释放时分别检查，不能在前摇走出边缘后凭空生成并扣次数。

遥控时镜头临时跟随鲨鱼，角色本人**不会随鲨鱼传送，仍然可见，未获得额外无敌**；清零主动横向速度与续跳，屏蔽人物方向、跳跃、开火、击掌和手势输入，同时保留特殊键状态识别二次按下。暂时禁用人物攀墙、攀边和挂顶输入，但继续走基类物理碰撞／运动流程，不能理解为无重力或冻结所有外力。

跑步中释放成功时立即把 `Running` 改为 `Idle`，遥控移动计算中也做兜底，不再保持跑步动作进入下潜。梯子状态和相应姿态保留。

### 潜行移动、梯子与电梯

左右控制独立鲨鱼，速度 **90px/s**，转向同时改变鲨鱼朝向；无左右或向下输入时不主动游动，但仍刷新脚下支撑。按住首次释放键不会马上跃出，需要第二次按下。

地形移动拆成最多 4px 的小步，前方在水线以上 4px 检查实体墙，墙前留 4px，不爬越垂直墙面。每步向下寻找真实地面，普通下降没有固定最大落差；下方完全没有地面则停止，不继续移出安全支撑。

梯顶／梯身提供当前高度支撑，**只左右移动不会自动沿梯子下坠**。只有按下方向键才忽略梯子支撑、转而寻找下方真实地面；可以只按下原地下移，也可以下加左右。按下不会穿透实体底板。普通地形的高度下降仍会跟随地面，不属于已删除的梯子自动下坠。

潜行地形射线忽略触发器、单位、Boss 伤害代理、FallingBlock、箱桶与普通 Doodad；**普通／巨型电梯虽然属于 Doodad，仍保留其实体碰撞**，可作为真实支撑或阻挡，不会被统一过滤掉。此规则也用于漩涡找地、寻路和两者共用的水平限位。

**鲨鱼潜行在电梯顶板上时，会自动随电梯上升、下降；巨型电梯斜向移动也会带走鲨鱼。** 无需持续按方向键，潜行姿态、剩余遥控时间和特殊次数保持原流程，电梯移动时仍能左右游动。跟随取实际支撑碰撞体的世界位移，不把鲨鱼附着到人物身上；游离顶板、顶板失效或开始跃出后解除跟随。静止时脚下实体地面降低或消失，也会重新找下方地面；没有任何地面则保留无底洞保护，不凭空向下移动。梯子仍保持高度，只有按下才主动脱离梯子支撑。暂停／零时间步不推进跟随。

潜行只显示背鳍与水纹，不造成伤害、不破土、不破坏物件、不拦截弹丸。初始代码帧 0–5 每帧 0.05 秒，之后 3→4→5→4 每帧 0.1 秒循环。

### 潜行恐惧与遥控时限

每约 **0.3 秒** 检查一次活敌：敌方 `playerNum<0`、横向距离不超过 64px、敌人脚底在水线下 4px 至上方 36px，并且无遮挡。符合者向远离背鳍方向惊慌 **0.6 秒**，后续检测可刷新；完全重叠时用鲨鱼朝向。尸体不恐惧，目标是否实际响应仍由其 `Panic` 实现决定。

遥控时限读取原版 Dredd 的 `specialRocketPrefab.life`，该资源不可用或寿命无效时回退 **4 秒**，不另写死一套假定的官方时长。再次按特殊攻击或超时都会触发同一个跃出流程，不再扣次数；已经跃出的鲨鱼不会被反复按键重置动画。

### 跃出、镜头与人物恢复

**跃出开始的瞬间移除鲨鱼临时镜头目标，镜头交回角色**。不等待 1.1 秒动画结束。人物使用 Dredd 同一路径的基类 `controllingProjectileDelay`，设置至少 **0.25 秒**的交接缓冲；原先更长的缓冲不会被缩短。

这段缓冲由官方输入逻辑处理，主要屏蔽方向与开火；没有自定义清空所有输入，尤其不能把它描述成连跳跃也一起禁止的全输入硬锁。缓冲结束后人物可正常行动，鲨鱼动画与伤害独立继续；鲨鱼实例清理前仍不能切换技能或再发一条鲨鱼。

跃出共 **1.1 秒**，代码帧 6–27 每帧 0.05 秒；6–26 为有效伤害帧，27 为透明收尾、不伤害。前 **0.45 秒** 用 smoothstep 额外向前冲 **24px**，高度保持原水线。前冲在水线以上 **12px、56px** 两条高度检测障碍，每步最多 4px，墙前留 8px；实体墙及上方平台均可能限位，不等同于潜行时的低位探测。

### 跃出伤害与清理

命中蒙版只来自鲨鱼身体层，剔除水层，以及被前景完全不透明水层遮住的身体像素；水花外观本身不造成猎杀伤害。普通单位使用 `(X,Y+6)` 采样点与当前身体像素接触，留 5px 余量，并检查视线。Boss 使用部件矩形。

每个目标一次 **28 点 `Explosion`**，朝向横力 **180**、上力 **420**。地形／物件每对象一次 **28 点 `Crush`**，同样冲力，保留物件免疫与水线下支撑保护；不额外做整画布范围爆炸。首次跃出伤害阶段产生 0.7 强度的位置震屏。

人物死亡、失能、对象禁用时结束猎杀并清理镜头与特效，不因此补一次正常交接缓冲。正常跃出时镜头只交还一次，动画结束清理仅兜底。猎杀全程不使用水体拦弹系统。

## 深海漩涡（maelstrom）

### 自动落点

自动寻找角色前方的最近有效活体 **Mook 及其派生类**，包括重装兵；要求敌方 `playerNum<0`、水平距离不超过 **180px**、高差不超过 **96px**，按二维距离最近选择。目标与角色之间不能有真实地形遮挡，且目标脚下 80px 内必须有真实支撑。载具、非 Mook Boss 等可以受漩涡伤害，但不因此成为自动定位对象。

没有合适目标时，尝试角色前方 **70px**；遇墙退到墙前 8px，再向下 80px 找地。无地时使用角色 **Y+2**。寻路忽略普通道具，保留电梯实体。生成后缩放 **0.85**，高度固定，不会持续追踪目标或重新寻地。

### 横向往返与平台阻挡

生成时预先检查落点左右各 **48px** 的实际可达端点。水平检测使用水线以上 **12px、56px** 两条射线，每步最多 4px，碰墙留 8px。因此**漩涡上半部遇到平台边缘，也会阻挡位移**；下方看似平坦不表示两条高度都畅通。当前实现保留这套碰撞限制。

路径按世界坐标固定为：**生成点 → 右端 → 左端 → 右端**，不会因人物面朝左就反过来。无障碍时总路程为 48+96+96=240px，均匀分配到 **3.6 秒**，约 66.67px/s；有墙时按实际可达路程分配速度，端点立即转向，不等待虚拟的墙后路程。运动中继续检查障碍；3.6 秒停在末端并消散 **0.6 秒**，总长 **4.2 秒**。

代码帧 0–4 每帧 0.05 秒起势，5–23 每帧 0.07 秒循环；24–31 每帧 0.075 秒消散。只有前 24 帧有持续吸附／周期伤害和水体拦弹；进入消散时另结算一次收尾。

### 捕获与吸力

第一次捕获要求当前可见水体像素接触敌人身体矩形，留 5px 余量。捕获后，在漩涡包围范围内进入旋转水片的透明间隙或漏斗口，仍可继续吸附；离开范围或被真实地形挡住时暂停作用，捕获记录保留，重新进入可恢复，不会隔墙持续追踪伤害。视线从目标所在高度检测，脚下平台不会仅因地面低位射线而挡掉暴露的上部接触。

持续吸力只作用于活着的 **Mook**，不对尸体、普通非 Mook 单位或 Boss 主体强设速度；受伤目标范围比吸力目标范围广。通过原版 `Knock` 施力，不改写目标位置，也不因 `canTumble=false` 就排除重装兵。

- 横向目标速度：`clamp((漩涡X-目标X)×6, -170, 170)`，趋近加速度 1200px/s²。
- 竖向目标速度：`clamp((水线Y+48×缩放-目标Y-6)×7, -160, 260)`，趋近加速度 2000px/s²，用于抵消下落并向漏斗中心拉起。
- `MookBigGuy` 及其派生类对 `Knock` 横力除 20、竖力除 5，本技能仅对持续吸力补偿对应倍率；捕获期间补 0.15 秒短眩晕，保留已有更长眩晕，清理 AI 输入并置为空中状态，恢复眩晕初始化清掉的横向吸力动量。

头顶障碍仍会限制被吸起的高度；其它攻击和漩涡收尾仍沿用目标原版抗击退，不因为持续吸力补偿而获得统一强制抛飞。

### 周期伤害与收尾

有效接触时，每 **0.4 秒**一次 **3 点 `Explosion`**，周期以生成时刻为基准，不为每个后来进入者另开计时器。第一次有效更新即可触发初次周期，全程最多 9 次；**3.5 秒起停止周期，3.6 秒时一次收尾 9 点**，单目标完整接触理论最多 **36 点**。

最后 0.1 秒不再追加周期，避免收尾撞上原版载具约 0.096 秒的连续受伤衰减；来自其它攻击的同时伤害仍可能触发原版限制。低帧率不会补发所有错过的周期，所以实际可低于理论上限。

收尾只作用于当时仍有效接触，或仍在捕获范围内且无遮挡的目标，单目标一次，横力远离中心 **220**、上力 **500**；Boss 部件仍需当时像素实际接触。离开者不会仅因曾被捕获就远距离受伤。收尾震屏强度 0.65。漩涡不破坏地形／场景物件，消散过程不继续吸附、周期伤害或拦弹。

## 深海涌泉（abyssal-spring）

### 七柱生成与错峰

第 3 施法帧一次创建七柱，预定横向相对角色位置为 **-90、-60、-30、0、+30、+60、+90px**。每次施法只扣 1 次。中柱立即开始，向左右依次延迟 **0.14、0.28、0.42 秒**，呈由中间向外扩散的效果。

每柱从角色 `(X,Y+14)` 向预定 `(X+i×30,Y+12)` 检查地形遮挡，遇墙退 8px；若实际横坐标偏离预定超过 12px，则跳过该柱，避免墙边挤堆。随后从 `Y+12` 向下 **55px** 找地，没有地面时回退角色 Y。被墙跳过意味着实际可能少于七柱，不会强行把所有柱挤到墙前。

最外侧两柱缩放 **0.9**，其余五柱缩放 **0.65**。每柱自身寿命 **1.4 秒**，28 帧、每帧 0.05 秒：代码帧 0–17 共 0.9 秒为有效阶段，18–27 共 0.5 秒消散。加最外延迟后，全阵列最长 **1.82 秒**，不是每柱都从施法一开始同时显现。

### 连续命中与击飞

普通单位使用 `(X,Y+6)` 采样点对当前柱体像素判定，留 5px 接触余量，并检查视线；Boss 使用部件碰撞矩形。每次 **4 点 `Explosion`**，同次施放的七柱以及同一 Boss 的所有部件共享计数和间隔：

- 每个目标整次施放最多 **7 次／28 点基础伤害**。
- 按实际命中时刻，后一次至少间隔 **0.12 秒**；相邻水柱不能在同一时刻各算一次，也不在低帧率时压缩补伤害。
- 首次命中横力远离柱中心 **70**、上力 **650**；后续命中冲力为 0，不反复重置抛飞。
- 离开柱体或墙挡时停止伤害，重新接触可继续剩余次数；下一次施法有独立预算。

柱体只在有效 18 帧拦弹，不破坏地形／场景物件。生成阵列产生 0.7 强度震屏，每柱开始显现时另有 0.5 强度的位置震屏。

### 人物移动

**已删除强制下坠、等待落地和落地后补放的机制。** 在释放帧直接按当前位置生成，不主动更改角色位置、横竖速度或附着状态。空中释放继续原版重力；梯子、滑索或墙动作按正常状态处理，不会由涌泉另施加坠落。施法仍有通用身体动画和动作限制，不能据此理解为取消所有原版施法约束。

## 接触、伤害、Boss 与弹丸拦截

### 四技能的像素接触

四技能特效源帧均为 128×128，导出 PNG 与命中蒙版来自同份正式源稿。图集边缘的透明区域不会因为位于画布内就造成伤害。接触余量为世界坐标 **5px**，按缩放换算到源像素。

| 技能 | 普通单位接触方式 | Boss 接触方式 |
| --- | --- | --- |
| 狂潮 | 身体矩形与可见水体像素 | `DamageRelay` 部件矩形与水体像素 |
| 猎杀 | `(X,Y+6)` 点与可见鲨鱼身体像素 | 部件矩形与鲨鱼身体像素 |
| 漩涡 | 首次身体矩形接触，捕获后允许包围范围内的水片间隙 | 每次部件矩形与水体像素 |
| 涌泉 | `(X,Y+6)` 点与柱体像素 | 部件矩形与柱体像素 |

狂潮、猎杀的物件接触，以及 Boss 部件矩形判定，会裁掉水线 `Y+1` 及以下部分，避免 5px 余量伤到支撑底板。普通单位接触和可见性检测按各技能专门逻辑执行，不能把四种技能统一理解为整张画布矩形或同一个圆形范围。

四技能伤害允许敌方尸体参与，由原版碎尸逻辑处理；猎杀潜行恐惧、漩涡自动索敌只找活体，漩涡吸力只作用于活 Mook。普攻水花则仅处理活体。所有技能都排除自身、无敌和游戏规则不允许攻击的目标。

### Boss、护甲与原版受伤逻辑

Boss 通过附近真实碰撞体的 `DamageRelay` 检测，主体不在 `Map.units` 或主体坐标远离水体时，暴露部件仍可受击。伤害经 `MapController.Damage_Networked` 交给部件原有逻辑，保留护甲、弱点开关和伤害类型转换，不绕过部件直接扣主体血。

同一主体的部件和常规单位通道共享命中记录，防止重复扣血。狂潮／猎杀每实例每主体一次；涌泉七柱共享七次预算；漩涡同周期防重复，收尾每主体一次。免疫 `Explosion` 或因其它碰撞体开启而关闭的部件，不消耗其它暴露弱点的有效命中机会。单位部件不作为狂潮移动阻墙，也不重复参与猎杀的物件伤害。

技能攻击对单位使用 `Explosion`，狂潮／猎杀对物件和地形使用 `Crush`；普攻普通水花使用 `Melee`，蓄力水爆使用 `Explosion`。实际扣血和实际移动均服从目标对应伤害类型的实现，表中冲力不是承诺最终位移距离。

### 水体拦截敌方弹丸

仅**狂潮、漩涡、涌泉**具有水体屏障，鲨鱼没有。屏障只在已显现且仍处有效动画帧时生效；延迟未显现、消散、死亡／禁用清理后或暂停时不拦弹。不是角色全身无敌或无条件防远程攻击，弹丸必须实际接触有效水体。

`WaterProjectileBarrier` 在原版 `Projectile` 各派生类自行声明的 `RunProjectile(float)` 运动／命中处理之前检测：结合弹丸本帧轨迹、水体相对位移和当前像素蒙版做扫掠，避免高速穿透。接触余量为弹丸半径（至少 0.5px）加 5px，而非只看弹丸中心是否落在画布中。

敌对关系取游戏的 `DoesPlayerNumDamage(弹丸玩家,角色玩家)`，友方弹丸放行；只由存活、有效且属于本端的角色执行拦截。命中后归零速度、停用并按网络／本地属性销毁弹丸，**不调用其 `Death`／`MakeEffects`，导弹被水熄灭时不会在角色脚下引爆**。此机制针对进入该 Projectile 运动路径的实体，不会消除已经生成的爆炸、近战或其它非弹丸伤害。

## 暂停、清理与联网

四技能的动画、位移和伤害按角色实际 `t` 推进，兼容游戏暂停及 TestMod 单帧调试；本帧未实际重算时间步时不会用旧 `t` 继续播放。普通／蓄力水花按 `Time.deltaTime` 推进，`delta<=0` 不播放、不检测后来进入的目标，动画结束立即销毁。水体屏障在弹丸时间步不推进时也不结算。

角色 `Update()` 每帧先清除时间步就绪标记，由 `SetDeltaTime()` 或击掌加速的 `SetHighFiveBoostDeltaTime()` 在取得正时间步后置位；基类被 TestMod 跳过时，自定义姿态同步和技能推进也停止。这里保留上一帧 `t`，供基类计算移动平台所需的 `lastT`，不能通过每帧先把 `t` 清零实现暂停。单步只放行该帧的自定义更新，击掌加速同样走就绪检查。

角色死亡会清掉其场上四技能，组件禁用同样清理；猎杀另外在失能时立即结束。不能把后者扩大成“任何失能都立刻取消所有其它水技能”。切换技能主动清理已有水体及其屏障；技能对象随角色建立父子关系，正常生命周期会释放判定登记与镜头引用。已起爆的普通／蓄力水花是独立短期对象，按自身寿命结束，不与技能列表清理混为一谈。

三叉戟只由 `IsMine` 的拥有端通过原版注册 prefab 网络生成，实例外观补丁也处理接收端，不修改共享资源。主动水花伤害、四技能伤害／吸力／物件处理和弹丸拦截只由拥有端执行，伤害继续调用游戏网络接口，避免各端重复结算；HUD 也只更新本玩家角色。上述是当前实现方式，**远程联机实际同步效果尚未验收**，不能仅凭使用网络接口宣称已通过联机验证。

## 动画、头像与 HUD

### 身体、移动和攻击动作

当前身体图集 **1024×640**、武器图集 **1024×288**，基础格 32×32。普通待机 1 帧、跑步 8 帧、跳跃／落地 24 帧，共 33 帧移动动作，使用生成表配对身体和去重后的 24 个手臂／武器姿势。普通跑步帧间隔 0.08 秒；爬梯外观帧间隔 0.1 秒，仅调整视觉，不改梯子移动速度。

直升机软梯运输期间，角色脚本可能被禁用，`Start()` 要等放下角色后才执行。因此在 `Awake()` 的 BroMaker 基类初始化完成、自定义材质已经换好后，立即刷新身体和武器的纹理尺寸缓存并重新计算、上传 UV；`Start()` 再刷新一次。角色首次挂在软梯上显示时即可按当前图集取帧，避免沿用 Rambro 的身体 1024×512／武器旧缓存造成多条横向三叉戟残片。刷新保留当前像素选帧，不改变直升机运动、角色上下梯逻辑或素材。

跳跃按 `abs(xI)>50` 分前进／原地，`yI>20` 为上升，`-55<=yI<=20` 为顶点和初降，`yI<-55` 为快速下落，各组三帧。空中按下键也使用完整身体，避免读取空白蹲姿帧。落地由基类直接衔接待机／跑步，没有另加 0.24 秒落地锁定或强制播放全部落地编辑帧。

站立／蹲姿蓄力起手先过 50ms 初始动作，再保持准备姿态，到 0.5 秒才循环蓝色水流；水流 16 帧循环共 0.533 秒。跑步、跳跃、梯子、滑索的水流循环为 16×40ms=0.64 秒，均不改变 0.5 秒满蓄力阈值。站立投掷收招三阶段为 66／50／66ms。

跑、跳、梯、索攻击把腿部和上半身独立组合，保留地形姿态和移动。竖梯使用独立 18 帧蓄力稿与 5 帧投掷稿，普通爬梯复用恢复持戟姿势，停止移动时保留当前裤腿阶段。滑索攻击优先于一般 Jumping 判断，读取合并的 27 帧正式滑索稿，不能误套空中攻击。

普通蹲持／蹲走的身体和武器来自同一源稿的同一帧，使用相同画布锚点与格号 `64–72`，蹲走每帧 80ms。基类更新后按**最终显示的身体格**同步武器；梯顶切换时即使状态仍为 `ClimbingLadder`、`ducking=false`，已显示的蹲姿也按此配对。不能改为武器帧回退一格或叠加旧 `(2,-1)` 偏移；攻击、近战、翻滚及特殊动作保留各自姿态。

普通爬梯继续调用基类动画与移动逻辑，`useNewLadderClimbingFrames` 和 `useLadderClimbingTransition` 均为 `false`；墙面攀爬的 `useNewKnifeClimbingFrames` 为 `true`，两类入口分别维护。角色不再接触梯子时保留基类已经选出的地面身体和武器，不把它重新覆盖为梯上分层姿态。兼容槽与禁用槽的构建约束见 [素材索引](aseprite-source/Readme.md#02_地形独立稿)。

近战源稿 8 帧、39×32，四技能施法稿为完整身体帧，播放时不叠加独立手臂；墙面、悬挂、翻滚、死亡、寄生死亡、击掌、秀肌肉等使用相应完整动作。死亡碎块使用独立源稿的头、身、双臂和腿部，金色三叉戟碎块层为空，不额外生成三叉戟碎块。

### 渲染层级

四技能使用 Z=1，位于敌人后、地形前；不是把水体前景盖在敌人之上。普通／蓄力命中水花使用 Z=-12。技能固定释放时的运动方向，人物之后转身不会把已释放特效反向镜像；猎杀潜行左右操作可以改变鲨鱼本身朝向。特效以世界位置更新，父级角色移动不代表技能跟着身体平移。

### 构建、关闭游戏与部署

在本项目目录执行。首次构建先准备本机配置和依赖：

```powershell
Copy-Item ./LocalBuild.example.json ./LocalBuild.json
```

在 `LocalBuild.json` 中设置 `AsepritePath`（可用 PATH 中的 `aseprite`）、`ReferenceDirectory` 和 `DeployDirectories`。默认依赖目录为 `.aquabro-buildrefs`，需自行放入 `Assembly-CSharp.dll`、`0Harmony.dll`、`BroMakerLib.dll`、`RocketLib.dll`、`UnityEngine.dll`、`UnityEngine.CoreModule.dll`、`UnityEngine.PhysicsModule.dll`、`UnityEngine.IMGUIModule.dll` 与 `UnityEngine.TextRenderingModule.dll`。这些依赖与本机配置均被 Git 忽略，不随角色发布。

构建命令：

```powershell
# 仅构建本地资源和 DLL
./BuildAssets.ps1 -SkipDeploy

# 构建并部署至 LocalBuild.json 配置的目录（先关闭游戏）
./BuildAssets.ps1
```

构建依赖 Aseprite 与系统 .NET Framework 3.5 编译器。工具路径优先使用 `-AsepritePath`，其次为 `AQUABRO_ASEPRITE_PATH` 环境变量、本机配置，最后从 PATH 寻找；依赖和部署目录可用 `-ReferenceDirectory`、`-DeployDirectories` 覆盖本机配置。没有配置部署目标时，省略 `-SkipDeploy` 会直接报错，避免将“未部署”误报为成功。

脚本在系统临时目录中生成图集、选帧表、像素蒙版及 DLL，生成和编译全部成功后才替换正式产物，完成后清理本次临时目录。`aquabro-build.rsp` 是不含本机路径的模板，由脚本展开为带引号的临时响应文件，兼容含空格的目录，不直接把模板传给编译器。项目文件统一从 `.aquabro-buildrefs` 引用依赖，也可在被忽略的 `LocalBroforcePath.props` 中覆盖 `AquabroReferencesPath`。输入源稿只用于读取和合成，不会由常规构建重新绘制覆盖。头像／图标导出进程会等待退出，避免未写完就复制。

**特效 PNG、图集选帧表和 DLL 内的命中蒙版必须配套更新**。只替换技能 PNG 不会让已经编译的伤害边界自动改变。默认部署会复制脚本列出的正式 DLL／PNG，并清除对应 `Aquabro.dll.cache`；配置单独维护，不能据此假定脚本会同步修改后的 JSON。

默认部署只处理已经存在的目标目录，目录缺失时会跳过，不自动创建。因此脚本输出 `deployment=True` 只表示启用了部署流程；实际同步到哪些目录，应以对应文件存在及源／目标哈希一致为准。

两个游戏目标目录及当前代码快照见 [部署与验证索引](当前角色实际应用状态.md#当前代码与磁盘部署)。代码或资源变动应同步更新对应机制文档与实际验证记录。部署前先关闭 Broforce（实际进程名 `Broforce_beta`）；只修改文档无需构建或部署。游戏可通过本机已有的 Broforce 启动快捷方式启动。
