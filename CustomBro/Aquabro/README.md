## 角色基础与操作

按键沿用游戏设置。海王保留原版跑跳、攀墙、爬梯、滑索和蹬墙翻身，没有额外跑速、跳高或抗酸能力。

| 操作 | 效果 |
| --- | --- |
| 按住攻击后松开 | 投出三叉戟；蓄力满 0.5 秒为强化投掷 |
| 近战／小刀 | 短按前刺；靠近可丢的小兵时按住，可抓起丢出 |
| 秀肌肉 | 按顺序切换四技能 |
| 特殊攻击 | 释放当前技能；遥控鲨鱼时再按一次使其跃出 |
| 遥控时左右／向下 | 移动鲨鱼／脱离梯子支撑，落到下方地面 |

## 普通攻击：三叉戟投掷

跑步、跳跃、爬梯、滑索和蹲下时都能蓄力投掷。蓄满可以继续按住，不会自动出手或继续变强；松手时按当前朝向投出，蹲姿出手低 3px。投出后冷却 0.2 秒，期间不累计下一次蓄力。投掷本身会惊动附近野生动物。

近战、施法、秀肌肉、失能等独占动作会清空蓄力，不补发投掷；动作结束后继续按住攻击，从零重新蓄力。

| 项目 | 普通投掷 | 满蓄力投掷 |
| --- | --- | --- |
| 飞行速度 | 400px/s | 664px/s |
| 水花伤害 | 8 | 内圈 14，外围只震飞 |
| 伤害持续 | 接触时一次 | 0.6 秒内可命中后来进入的敌人 |

戟尖可打到贴身目标，首次接触就产生一次水花并销毁，不穿透连续起爆。戟尖直击和水花不叠算两份伤害；实体墙会挡住投掷。普通投掷也能破坏地形和附近物件，并可能撞到敌方火箭、提前起水花；火箭按自身规则受伤或爆炸。

撞墙后不会留下能踩的三叉戟，也不会把小兵串在戟上带着飞；命中后直接变成水花。

### 普通水花与蓄力水爆

普通水花伤害半径 12px，后续动画仅供显示。蓄力水爆按可见水花接触身体判断：距爆心 25.2px 内伤害，外围只震飞；每个敌人只算一次，先被外围震飞后进入内圈也不补伤害。部分 Boss 弱点只擦到外围时不受伤、不震飞，之后进入内圈仍可命中。

墙后目标不受伤、不震飞；蓄力水爆结束前拆掉墙，可以打到新露出的目标。地形、物件和附近可受伤敌弹只在起爆时处理一次，破坏范围与打人范围不同。水花消失后不留伤害或减速水洼。

## 近战：前刺与丢兵

地面、蹲姿和空中均可使用，伤害与范围沿用原版小刀。约 0.114 秒命中、0.179 秒结束；地面可半速移动，空中正常下落。

前刺会结束长按跳跃带来的继续抬升；刚起跳就前刺，可能比一直按住跳跃跳得低，不会在空中悬停。

靠近普通小兵时，按住近战键会抓起并朝面前丢出，不会先刺伤它；短按仍是前刺。重装兵等原版不能丢的敌人，以及附近没有目标时，按住也只会前刺。丢兵和扔回手雷沿用原版规则。

## 技能选择与施法通则

初始为怒海狂潮，四技能共用 **5 次**。秀肌肉依次切换：**怒海狂潮 → 深海猎杀 → 深海漩涡 → 深海涌泉**。图标显示在原版特殊次数栏，各玩家独立选择；同一游戏进程内重生保留选择。

- 每次举戟约 0.13 秒后释放并扣 1 次，空放也扣；涌泉七柱合计一次，鲨鱼跃出不另扣。切换不补次数，补给和重生沿用原版规则。
- 前刺、施法或遥控鲨鱼时不能切换；当前施法动作结束后才能接下一次。
- 狂潮、漩涡、涌泉可在空中放，不强制落地；鲨鱼需要支撑，详见下节。
- 切换和人物移动不带走已放出的水体。可连续叠放狂潮、漩涡、涌泉，各次分别计算伤害；鲨鱼跃出后可放其它技能，旧鲨鱼结束前不能再放第二只。
- 看起来有浪、有水柱，也不能踩在上面当平台；敌人仍可穿过，是否受伤、被卷起或打飞另按各技能规则处理。

| 技能 | 单目标基础伤害 | 场景破坏 |
| --- | --- | --- |
| 怒海狂潮 | 普通兵、机枪胖兵和手雷胖兵一次 26；其余大型敌人、载具、Boss 每次 2，整次最多 26 | 地形和物件 |
| 深海猎杀 | 潜行无伤，跃出一次 28 | 飞行中破坏地形和物件；入水后仅保留箱桶、牢笼和锯齿等接触伤害 |
| 深海漩涡 | 每次 3，最多九次；收尾 9，总计最多 36 | 箱桶、牢笼和锯齿，不破坏普通地形 |
| 深海涌泉 | 每次 4，同次七柱合计最多七击／28 | 箱桶、牢笼和锯齿，不破坏普通地形 |

上限需要持续接触且目标允许受伤，不保证打满；成功腐蚀后的融化死亡另按原版酸液规则处理。

## 怒海狂潮（tidal-wave）

沿释放方向水平推进，速度 160px/s；有效 1.5 秒，最多前进 240px，再消散 0.5 秒。

浪沿释放时的高度直走：空中释放不会自动落到地面，经过坑口也不会掉到坑底，不会顺着地势爬上台阶。

- 机枪胖兵 `MookBigGuy`（含子类）和手雷胖兵 `MookGrenadier` 同次水墙只受一次 26 点基础伤害；即使存活也不挡停，不按剩余血量强制击杀。成功触发毒水腐蚀时仍沿用原版酸液效果。
- 普通兵、箱桶和牢笼不挡停；除上述两类外，活着的大型敌人、载具、实体 Boss 和存活墙体会挡停，停留期间继续攻击。
- 挡路目标死亡或障碍解除后，使用剩余时间继续前进，不延长寿命。
- 水线下支撑底板受到保护。

## 深海猎杀（shark-hunt）

起手和出手时都需要地面或梯子支撑；跳跃、下落、墙动作和滑索中不能起手。出手前失去支撑会取消，不扣次数。

- **遥控**：镜头跟随鲨鱼，人物留在原处、无法主动操作，没有额外无敌；脚下被打空仍会下落。鲨鱼左右速度 90px/s，可掉头，松键或同时按左右停下；潜行只让附近无遮挡活敌惊慌，不攻击、不拦弹、不吸毒。
- **支撑**：有底深坑会直接降到坑底，无底洞前停下；梯子上左右移动保持高度，按下才脱离梯子，不能穿实体地板。电梯顶板可带着鲨鱼移动，Boss 顶面可支撑但不会带着它走。
- **台阶与箱桶**：潜行能降到低处，但爬不上一格高的垂直台阶，碰到就停。箱桶挡不住也托不住潜行鲨鱼，不会被潜行撞坏；站在箱桶上召唤时，若下方有真正的地面，鲨鱼会出现在下方地面。
- **跃出**：松开特殊键再按，或遥控到时后自动跃出；一直按住首次施放键不会提前跃出。时限沿用原版 Dredd 遥控导弹寿命，资源不可用时为 4 秒。跃出立即交回镜头，至少约 0.25 秒后恢复人物操作。
- **飞行**：沿最后朝向向前上方跃出，不能再转向，之后受重力下坠；同高地面约前进 64px。墙挡前进，顶部障碍中止上升；深坑中继续飞行下坠，实际触地才入水。无底洞最多飞行 4 秒。
- **入水**：收尾约 0.45 秒。起跳和落点水花各自固定，伤害只跟鲨鱼本体走；鼻尖触水首帧仅显示本体，下一帧没入时才起水花。入水后露出的本体仍能命中，最后约 0.05 秒仅显示画面；每个目标同次最多受击一次。

## 深海漩涡（maelstrom）

出现在前方最近活敌下方的地面；步兵、重装兵、坦克、机甲和露头虫类均可成为目标。能选作落点，不代表能被卷起。

- 找目标限水平 180px、高差 96px，要求无遮挡、可受伤且下方 80px 内有地面。“最近”包含上下距离，身后敌人不参与。
- 无目标时尝试前方 70px，遇墙退到墙前约 8px；仍找不到地面时，在接近人物当前高度处展开。生成后不追踪敌人、不重新找地。
- 在生成点左右各 48px 内按 **起点 → 右端 → 左端 → 右端** 往返，共 3.6 秒，再消散 0.6 秒。不论海王朝哪边，路线都先朝画面右边；右边贴墙时，向右这一段可能很短或没有。墙与上方平台边缘挡住移动；拆墙仅扩大剩余路线，不重走已完成的折返或延长时间。
- 生成后只左右移动，高度不再改变；经过坑口不会掉下去，地板被炸掉后也不会下沉，不能指望它追到坑底继续卷敌人。
- 普通兵、重装兵、狗、异形和地狱小兵等会受到吸力；死后留下的完整尸体也能卷起，战斗中刚被杀死的目标可继续被卷动。碎肉和残肢不单独吸取，正在中酸融化的目标不拉扯。
- 多个敌人被卷入后，会各自在水中错开位置、上下左右翻动，不会全部挤在同一个点；活着的重装兵被持续卷住时还会被打断行动。
- 已卷入的敌人在水片间隙仍可被吸附，离开范围或隔墙则停止。装甲兵和特殊 Boss 受原版抗推影响；坦克、大型机甲、直升机和虫类不会被持续卷起，详见 [可吸取目标](docs/UtilityMod验证指南.md#哪些敌人会被卷动)。
- 每 0.4 秒伤害一次，收尾再打并向外上方甩飞；触发或继续腐蚀时不甩飞。严重卡顿错过的伤害不补发。

虫类按露出的可受伤部位找地；缩回、护甲保护时可能选不到。沙虫本体与钻地车地下状态的区别见 [敌人验证指南](docs/UtilityMod验证指南.md)。

## 深海涌泉（abyssal-spring）

以人物为中心，每隔 30px 向两侧展开，最多七柱；中柱先出，两侧延迟 0.14／0.28／0.42 秒。每柱有效 0.9 秒、消散 0.5 秒。

- 可沿一格高台阶展开，高墙取消墙后水柱；箱桶、牢笼、栏杆不挡展开，其后的真墙仍挡。
- 位置释放时一次决定；之后拆墙不补柱，地板或电梯移动不重新找地。找不到地面时沿用人物或展开途中上一处的高度，因此可以悬空生成。
- 左三柱朝左，中柱和右三柱朝右，不受人物朝向影响；最外两柱更大，伤害相同。
- 同一根柱可以反复命中，但整组对同一敌人共享最多七击和至少 0.12 秒间隔。仅第一击向上、远离命中柱击飞；同时碰多柱时右柱优先。

## 毒液污染与腐蚀（狂潮、漩涡、涌泉）

只有这三种技能能染毒。普通投掷的水花、蓄力水爆和鲨鱼都不会吸毒变绿；旁边已经有毒水，也不会让新投出的三叉戟带毒。

有效水体接触无遮挡的敌方酸弹、酸池，或敌人死后留下的腐蚀地面酸液后染毒，每个不同来源升一级，最多两级：

| 水体 | 触发腐蚀概率 |
| --- | --- |
| 蓝色清水 | 0% |
| 浅绿毒水 | 50% |
| 鲜绿毒水 | 100% |

- 每次有效命中分别尝试，没触发就造成普通水伤害。水后来变毒不补算旧命中；漩涡、涌泉若还有后续命中可再试，同道狂潮已打过的普通兵不能补试。
- **同次涌泉整组共享毒水**，晚出的柱继承等级；不同次、不同技能互不传染，新放出从清水开始。
- 每级变色约 0.3 秒，腐蚀概率吸收时立即生效；毒水不变回清水，也不延长寿命或补回攻击次数。
- 酸池不会被吸干，同池不重复升级；一片连通酸池可能包含多个来源。重叠水体按生成顺序由首个有效接触者吸收酸弹；鲜绿水仍会吃弹，可能让后面的清水分不到毒液。消散时不再吸毒，鲨鱼全程不参与。
- 敌人死后留在地板、墙面或天花板上的腐蚀酸液也能染毒，接触同一份不会反复升级；一片酸液铺在多块地形上时，可能直接升到鲜绿。吸收不会清掉地面的酸液，普通血迹和绿色装饰不算毒液来源。

成功腐蚀会让敌人变绿、惊慌，按原版规则融化；这一击不额外打飞，漩涡也停止吸起中酸敌人。后续毒水继续保留酸液效果；清水和其它攻击仍可能提前打碎它。已附着的酸液不会因水体结束、切换技能或海王死亡解除。

变绿不是伤害翻倍，也不是先扣表里的伤害、再额外补一份毒伤；成功触发时，这一击改为让敌人中酸，再走原版的惊慌和融化过程。因此，高血量但怕酸的敌人也可能被融化，不能只看技能表里的累计伤害判断能否杀死。

普通兵、重装兵、盾牌兵和三种自爆兵等可腐蚀；普通与重装自爆兵中酸后不再自爆。异形、普通飞蚊、载具、Boss 部件和不能被酸液附着的敌人保留普通技能伤害，地狱飞骷髅沿用特殊酸液反应。具体敌人和限制见 [酸液敌人核对](docs/酸液敌人核对.md)。

## 接触、伤害、Boss 与弹丸拦截

- 合作闯关时，水攻击不会直接伤害队友，队友的子弹也能穿过水体；对战模式里，其他玩家可以被水攻击命中，其射来的弹丸也可能被水挡下。漩涡不会自动选其他玩家脚下生成，鲨鱼潜行也不会吓跑其他玩家。炸掉地板或引爆箱桶造成的危险仍按原版处理。
- 水体按当前有效形状命中，透明画布不算范围，边缘保留 5px 余量；实体墙遮挡攻击、拦弹和吸毒。Boss 保留护甲、弱点和阶段规则，同一部位碰到水的多处也不重复扣血，独立弱点分别计算。
- 狂潮、漩涡、涌泉能持续熄灭接触的敌弹，不限发数，友弹通过；导弹被熄灭时不爆炸。伤害次数用完仍可挡弹，消散后停止攻击和拦弹；近战、已有爆炸不受保护。
- 普通水花和蓄力水爆没有持续挡弹能力；蓄力水爆碰伤附近火箭时，火箭反而可能按原版规则爆炸，不能拿它当水技能那样的挡弹屏障。
- 普通手雷不会像子弹、火箭那样被水体直接熄灭；敌人把手雷扔进水中时，仍要躲避爆炸。
- 固定锯齿先打落，脱落无敌结束后才能继续摧毁。四技能可打碎敌方尸体，普通投掷和蓄力水爆只伤活体。
- 海王被打晕时，狂潮、漩涡和涌泉继续，鲨鱼立即结束；死亡或禁用清理全部场上技能。暂停不推进技能、污染或腐蚀。

猎杀跃出、涌泉释放及各柱出现有轻震；漩涡无自定义震屏，蓄力水爆仅靠近人物时轻震。动画与渲染细节见 [技术说明](docs/机制实现细节.md#动画头像与-hud)。

## 构建、关闭游戏与部署

首次复制 `LocalBuild.example.json` 为 `LocalBuild.json`，设置 Aseprite、依赖和部署目录，再执行：

```powershell
./BuildAssets.ps1 -SkipDeploy  # 仅构建
./BuildAssets.ps1             # 构建并部署
```

部署前终止 Broforce 并确认退出；DLL、PNG、图集和命中蒙版必须配套更新，脚本同时复制角色 JSON。必要实机验证和清理结束后默认关闭游戏。只改文档无需构建或启动游戏。

完整依赖与复制规则见 [构建说明](docs/机制实现细节.md#构建关闭游戏与部署)，实际部署与验证范围见 [当前状态](当前角色实际应用状态.md)。
